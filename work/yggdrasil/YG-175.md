## Visão

Hoje cada **linguagem** é uma ilha: um `LexiconPack` (idioma, música, domínio) vira
uma sala caminhável (YG-167) com seu próprio loop de bits (YG-168). Não há **tecido
conectivo entre ilhas** — eu não posso ligar um *odù* yorubá a um termo *mbyá*, nem
construir o sentido de uma palavra nova como **soma de insights** de palavras que já
sei em guarani / português / música / matemática.

O **universo centralizado** é essa camada que faltava: **uma única topologia de
sentido cross-linguística** que federa todos os packs num só grafo. Não é uma nova
ilha — é a ponte entre as que já existem.

Invariantes do dono (herdados de YG-155): **conteúdo × forma** (o termo canônico mora
em **CO/markdown** = conteúdo; o Yggdrasil é a **forma** navegável), **memory-light**,
**engine-neutro** (pronto p/ cliente 3D futuro). **Linguagem é os dois:** conteúdo (o
léxico que estudo) *e* forma (o meio em que o sentido se expressa — por isso **música**
e **matemática** são linguagens abstratas de primeira classe, `kind` do pack).

## Abstrações

| Abstração | Concretização |
|---|---|
| **Nó** | qualquer `PackEntry` de qualquer `LexiconPack` (`kind = language\|music\|domain`). Identidade estável `NodeId = "{pack_id}:{term_slug}"` (fold de diacríticos/tom, como `comunicacao::lexicon`). |
| **Aresta** | relação **cross-pack** que hoje não existe. Criada por **exploração**: a co-visitação registrada na telemetria (YG-145) materializa uma aresta candidata; o usuário pode confirmá-la/nomeá-la (`relation`), mas a telemetria sozinha já basta p/ existir. |
| **Referência** | mídia/contexto **não embutido** — frase-instância, etimologia, áudio — anexada por **link** (URL/term_path no CO), nunca copiada pro nó. |
| **Linguagem-conteúdo** | o léxico = conjunto de nós que estudo. |
| **Linguagem-forma** | o meio: idioma natural, **música**, **matemática** como semiótica abstrata. Extensível a novas linguagens = só mais um pack; o modelo nó/aresta não muda. |

## GIVEN / WHEN / THEN

GIVEN cada `LexiconPack` (YG-155) carrega entradas com `term/gloss/role/relations` e
posição abstrata, é caminhável (YG-167) e rende bits (YG-168), MAS as `relations` são
**intra-pack** — não há identidade de nó nem aresta **entre** packs/linguagens, e a
telemetria de exploração (YG-145) não vira grafo,

WHEN introduzirmos o **universo centralizado** como uma camada de domínio
`yggdrasil-core/src/comunicacao/topologia.rs` (+ rotas em `yggdrasil-web`) que:

1. **Identidade de nó cross-pack** — `NodeId = "{pack_id}:{slug}"`, resolvível p/
   qualquer pack registrado; um índice em memória (memory-light: lazy, `MAX_RESIDENT`)
   que mapeia `NodeId → (pack, entry)`.
2. **Arestas por exploração** — um `EdgeStore` (SQLite, tabela `topo_edges`:
   `a NodeId, b NodeId, weight, relation?, source = explore|user, created_at`).
   A telemetria de co-visitação (duas entradas vistas em sequência na mesma sessão)
   **incrementa `weight`** de uma aresta `source=explore` (idempotente por par
   ordenado-canônico). O usuário pode **promover** uma aresta a `source=user` e dar-lhe
   um `relation` (ex.: "cognato", "mesmo conceito", "rima sonora").
3. **Referências por link** — `topo_refs` (`node NodeId, kind = sentence|etymology|audio|link, href, label`).
   `href` aponta pro CO (term_path/markdown) ou áudio (params de síntese do pack) —
   **nunca** copia o conteúdo. Reaproveita o round-trip de leitura do `comunicacao`.
4. **Travessia** — `GET /api/v1/topologia/no/{id}` devolve o nó + vizinhos
   (arestas ordenadas por weight) + refs; `GET /api/v1/topologia/grafo?around={id}&depth=`
   devolve um subgrafo p/ render. A travessia **atravessa linguagens** (de um nó yorubá
   p/ um mbyá por uma aresta que o usuário criou).

THEN o caso de uso do dono fecha em loop:
**leio um odù yorubá → vejo conexão com termo mbyá → ligo por exploração (telemetria
basta) → abro instâncias em frases + etimologia (refs por link) → entendo o sentido →
formo a imagem mental da palavra nova como SOMA de insights** de palavras que já sabia
ou acabei de aprender em guarani/português/qualquer língua, ou mesmo semiótica abstrata
(música, matemática). O grafo é a "tradução de lógica em verdade objetiva": o sentido
**emerge das relações**, exatamente como bits emergem de aprender (YG-168).

## Contrato HTTP (novo)

```text
GET    /api/v1/topologia/no/{id}                 → { node, neighbors[], refs[] }
GET    /api/v1/topologia/grafo?around=&depth=    → { nodes[], edges[] }  (subgrafo)
POST   /api/v1/topologia/aresta                  ({ a, b, relation? }) — promove a user-edge
POST   /api/v1/topologia/explorar                ({ from, to }) — telemetria → weight++ (explore)
POST   /api/v1/topologia/no/{id}/ref             ({ kind, href, label })
```

Auth via `sub` do JWT (mesmo padrão de `comunicacao_routes.rs`). Anônimo pode
**ler** o grafo; criar aresta/ref exige login (atribuição = autoria, como o `publicar`).

## Frontend

`static/universos/topologia.{html,js}` — render do subgrafo (canvas; reusa o feel do
Mundo/lobby). Pisar/clicar num nó → inspector (glosa + refs + áudio do pack); arrastar
de um nó a outro → cria aresta `user`. A travessia entre nós de **packs diferentes** é
o que materializa o "universo centralizado" pro usuário.

## Fora de escopo (explícito)

- Inferência automática de cognatos (NLP) — arestas vêm de exploração/usuário, não de
  modelo. (Gancho futuro.)
- 3D — engine-neutro; o subgrafo é dado, o render 2D é uma forma entre várias.
- Edição do conteúdo canônico — refs **linkam** pro CO; escrita de termo continua via
  `comunicacao::publicar` (YG já existente).
