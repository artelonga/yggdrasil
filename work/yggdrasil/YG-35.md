GIVEN scenes + signals + multiplayer + JWT funcionam isolados
(YG-32..YG-34), mas nenhum universo de jogo de verdade foi feito,
WHEN construo `PokerTable.tscn` end-to-end (6 assentos, bot
fallback, buy-in/cash-out chamando Rust, gameplay com signals)
e rodo paralelo à versão canvas (YG-23/25/26/27 do trilho Rust),
THEN tenho **dados reais** para a decisão de migração: comparar
dev velocity, peso do payload, ergonomia mobile, custo de deploy.

## Por que é o último task do POC

Esta é a tarefa-decisão. Se YG-35 sair em prazo razoável e o
resultado superar a versão canvas em developer experience + UX
multiplayer, marcamos para migrar snake/tetris/invaders em YG-36+.
Se sair pior ou demorar 2x mais, mantemos o trilho canvas e
arquivamos `yggdrasil-godot/` como aprendizado.

## Decisão registrada (spike YG-35, 2026-06-08)

A decisão de migração foi resolvida via spike timeboxed. Ver
[`docs/adr/YG-35-godot-vs-canvas.md`](../../docs/adr/YG-35-godot-vs-canvas.md).

**Veredito: HÍBRIDO — não migrar.** Canvas/Rust permanece o cliente de produção
do v3.0 (é o caminho crítico, a um `CO-384` do lançamento, e dono do seam de
federação co-bridge). Godot é retido **apenas** para o universo 3D `anatomy3d`,
onde o 3D nativo é a única vantagem real medida. O resto de `yggdrasil-godot/`
(lobby, jogos 2D, grid_editor, poker local) é congelado como laboratório.

Motivo central: o POC **não construiu** os pilares que justificavam migrar —
YG-33 (signal bus/event-sourcing), YG-34 (multiplayer WS+JWT gateway) e a
composição de scenes de YG-35 têm **0 LOC** (sem `@rpc`, sem `WebSocketMultiplayerPeer`,
`signal_bus.gd` com 7 linhas). Sem multiplayer e sem `POC-METRICS.md`, a regra de
decisão ("migrar se superar canvas em dev-velocity + UX multiplayer") não pôde ser
satisfeita. O pôquer multiplayer server-authoritative já existe e está pronto no
lado Rust (epic YG-22, release 0.8.0).

Follow-ups propostos: YG-36 (extrair anatomy3d para export web embutido),
YG-37 (medir payload/COOP-COEP/mobile), YG-38 (arquivar Godot 2D). Marcar
YG-32/33/34 como `descoped`.
