## As
Usuário escrevendo notas de universo (anotações + ligações).

## I Need
Que escrever e navegar notas seja **primário**, não um modo escondido do editor de instâncias: um template `jardim` dedicado, busca de notas, e uma visão notes-first (lista + grafo de wikilinks).

## So That
Começar a anotar é imediato (criar universo "jardim" → escrever), e o grafo de ligações é a visão principal.

## Context
Hoje as notas vivem como blocos no editor de instâncias (Phase 0). Estender:
- `yggdrasil-core/src/instance/template.rs` — novo `jardim_template()` (palette = só `note`, grid leve), no padrão de `blank_template`/`neuroanatomia_template`.
- `static/universos/instance.js` — busca client-side sobre `state.notes` + toggle de visão "grafo" usando os wikilink edges já renderizados.

## Acceptance
- **GIVEN** `GET /api/v1/templates`
  **WHEN** lista
  **THEN** inclui `jardim`; criar instância com `?template=jardim` dá palette só-`note`.
- **GIVEN** uma instância com N notas
  **WHEN** digito na busca
  **THEN** a sidebar Notas filtra por título/corpo (client-side, sem API).
- **GIVEN** a visão grafo
  **WHEN** ativada
  **THEN** mostra notas como nós e wikilinks como arestas (reusa `state.graph`); clicar num nó seleciona a nota.

## Dependencies
