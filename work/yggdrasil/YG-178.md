## Visão (companheiro de leitura física)

Você lê o livro físico (Ayvu Rapytã, dicionário Mbyá, futuramente Ifá) e a
ferramenta é o **companheiro Duolingo-like**: ao encontrar uma palavra, você a
**reivindica** — ela vira **sua**. O léxico é de todos; **suas palavras, suas
arestas e seus nós são seus**. Com o tempo, sua **constelação pessoal** cresce: só
o que você tocou acende. É a aquisição por contexto do caso fundador, tornada
pessoal — "a imagem mental da palavra nova como soma de insights de palavras que eu
já sabia ou acabei de aprender".

## Fluxo de uso

1. Ler um verso/entrada no livro → abrir a sentença na ferramenta (ler-primeiro) ou
   buscar a palavra.
2. Toda palavra começa como **palavra-léxico** (compartilhada, **ainda não minha** —
   oca/apagada).
3. **Clicar uma palavra → vira "minha"** (visitada). Rever avança o status
   **visited → learning → known** (SRS de `comunicacao/review.rs`).
4. Ao longo das sessões, o subconjunto pessoal cresce — só *minhas* palavras
   destacadas.
5. Eu traço **minhas arestas** (conexões que percebo) e adiciono **meus nós**
   (palavra que ouvi, fora do léxico) — **privados**.
6. Toggle **"só minhas"** filtra a galáxia ao *meu* subconjunto, sobre o léxico
   compartilhado.

## Modelo de dados (por `sub` do JWT)

Os nós do léxico continuam **compartilhados**; uma **camada privada** por usuário:

| Camada | O quê | Tabela (SQLite, `YGGDRASIL_DB`) |
|---|---|---|
| **Minhas palavras** | reivindicar + status de aprendizado | `user_words(sub, node_id, status, seen_count, first_seen, last_seen)` |
| **Minhas arestas** | conexões próprias | `user_edges(sub, a, b, relation?, created_at)` |
| **Meus nós** | palavras que adiciono (fora do léxico) | `user_nodes(sub, id=user:{sub}:{slug}, term, gloss?, created_at)` |

`status`: `visited | learning | known` (ou nível 0..n). `node_id` resolve no léxico
(`resolve_node`) **ou** é um `user_nodes` próprio. Par canônico nas arestas (como o
global). Tudo idempotente.

## GIVEN / WHEN / THEN

GIVEN a topologia tem nós do léxico **compartilhados** e overlays de cosseno globais,
MAS exploração/relações são globais e **não há noção de "minha palavra"** nem
progressão de aprendizado por usuário,

WHEN adicionarmos uma **camada pessoal** (auth por `sub`, espelhando o padrão
per-user do `comunicacao`):

1. **Reivindicar/aprender** — `POST /api/v1/me/topologia/visitar { node }` faz
   upsert em `user_words` (cria `visited`; revisões avançam o status via SRS).
2. **Aresta própria** — `POST /api/v1/me/topologia/aresta { a, b, relation? }` →
   `user_edges` (privada; o `/explorar` global da YG-175 vira **por usuário**).
3. **Nó próprio** — `POST /api/v1/me/topologia/no { term, gloss? }` → `user_nodes`
   (`id = user:{sub}:{slug}`), entra no grafo só do dono.
4. **Ler o meu** — `GET /api/v1/me/topologia` → minhas palavras (com status),
   arestas e nós; e `/grafo` aceita `?mine=true` p/ filtrar ao subconjunto.

THEN cada usuário tem **seu próprio grafo** sobre o léxico comum: clicar reivindica,
rever ensina, e a constelação pessoal é o mapa do que ele caminhou — distinta e
privada, sobre o substrato compartilhado.

## Frontend

- Palavra-léxico **não-minha**: oca/apagada. **Minha**: preenchida, cor por status
  (visited fraco → learning → **known/ouro**), com anel. Minhas arestas: estilo
  próprio. Meus nós: forma distinta.
- Clicar uma palavra (logado) = **visitar** (vira minha / avança). Toggle
  **"só minhas"** (e contador "N palavras minhas / streak").
- Anônimo: lê o léxico; **logar** desbloqueia reivindicar/arestas/nós.
