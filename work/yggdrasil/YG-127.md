## Visão
Seção de analytics ao vivo padrão da casa: coleta privacy-first (zero PII,
ip_hash com salt diário no servidor do CO, DNT/opt-out no client), APIs
públicas PII-stripped, stream em tempo real, dashboards público+admin.

## Fase 1 — feita nesta execução (v2.15.0)
- [x] `static/telemetria.js`: tracker no contrato da ArteLonga (`{schema:1,
      batch:[…]}` → `POST co/api/v1/telemetry/events`, `site: "yggdrasil"` →
      universe_key). page_view, page_end (duração), js_error; vid/sid opacos;
      DNT/opt-out (`ygg_optout=1`); fila local + sendBeacon; hook
      `window.yggTelemetria.track()` para eventos de app.
- [x] Incluído em 15 páginas (landing, lobby, login, feedback, neuro, universos/*).
- [x] `src/co_rollups.rs`: push horário (upsert idempotente) dos agregados de
      JOGO (`TelemetriaDb` → `POST co/api/v1/analytics/public/rollups`),
      env-gated (`YGG_CO_ROLLUP_TOKEN`; sem token → no-op). Só agregados
      anônimos — nenhum evento cru.
- [ ] OPS (pendente de autorização): gerar token e setar `CO_ROLLUP_TOKEN`
      no co-artelonga + `YGG_CO_ROLLUP_TOKEN` no yggdrasil-artelonga.
