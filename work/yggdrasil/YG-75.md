## As

A developer que precisa carregar e salvar instâncias de universo

## I Need

Um `InstanceStore` que persiste `UniverseInstance` em **disco como fonte da
verdade** e mantém um **índice SQLite fino** para listagem/ownership rápida

## So That

Instâncias são inspecionáveis/diffáveis em disco (princípio do `co`), anexos
binários não incham o SQLite, e listagem por owner/publish é rápida sem ler cada
arquivo

## Context

Ler `docs/architecture/editor.md` (§ "Persistência"). Espelha a divisão do repo:
SQLite para dados derivados/consultáveis, arquivos para conteúdo autorado.

### Reuso do `co` (decisão em aberto #1 — resolver aqui)

`yggdrasil-core` ainda **não** depende do `co/core` (só de `game-core`). Adicionar
dep por path `co/core` no `yggdrasil-core/Cargo.toml` e pinar (CLAUDE.md: "Reuso >
Reescrita", "congelar dependência do co"). Reusar `co/core/src/storage.rs`
`ContentStore` (escrita atômica temp+rename). Como `ContentStore::write` hoje só
aceita `&str`, **adicionar `write_bytes`/`read_bytes`** — abrir issue no `co` e
fazer a mudança lá (não modificar o `co` a partir do Yggdrasil); se inviável a
curto prazo, portar os ~120 linhas para `yggdrasil-core/src/instance/store.rs` e
documentar a decisão no CHANGELOG.

### Layout em disco

```
data/instances/                      # YGGDRASIL_INSTANCES_DIR (env, default)
  <instance_id>/instance.json        # UniverseInstance (escrita atômica)
  _blobs/<shard>/<hash>             # anexos content-addressed (YG-77 popula)
```

### Índice SQLite

No DB de `YGGDRASIL_DB` (mesmo de scores/telemetria). Criar via `execute_batch`
como `telemetria::init_telemetry_db`:

```sql
CREATE TABLE IF NOT EXISTS instances (
  id TEXT PRIMARY KEY, owner TEXT NOT NULL, title TEXT NOT NULL,
  template TEXT, published INTEGER NOT NULL DEFAULT 0,
  created_at TEXT NOT NULL, updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_instances_owner ON instances(owner);
```

## Acceptance

- `yggdrasil-core/src/instance/store.rs` define `InstanceStore` com:
  `create`, `load(id)`, `save(instance)` (escrita atômica), `delete(id)`,
  `list(owner)`, `list_published()`, e `reindex()` (varre o disco e reconstrói a
  tabela `instances`).
- `InstanceStore::new(root, db)` cria `data/instances/` e a tabela se ausentes;
  `YGGDRASIL_INSTANCES_DIR` configura o root (default documentado).
- `save` grava `instance.json` atômico E faz upsert na tabela; `updated_at` é
  bumped no save.
- `reindex()` no boot reconstrói o índice a partir dos `instance.json` em disco
  (índice descartável) — teste: apagar linha do SQLite, `reindex()`, linha volta.
- `co/core` adicionado como dep por path e pinado (ou port documentado).
- Testes: round-trip create→save→load idêntico; `list(owner)` filtra correto;
  delete remove arquivo + linha; reindex reconstrói.
- `cargo test -p yggdrasil-core`, `clippy -D warnings`, `fmt --check` limpos.
- CHANGELOG `[Unreleased]` atualizado; bump minor.
