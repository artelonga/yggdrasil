## As

A visitor que quer ver o atlas 3D no navegador, sem instalar nada

## I Need

O visualizador 3D de anatomia (YG-83) **exportado para a web** (Godot HTML5/WASM)
e servido online pela plataforma

## So That

A experiência 3D interativa fica acessível por URL (`/anatomia`), na mesma infra
que já fazemos deploy — sem cliente nativo.

## Context

- **Export single-thread** (decisão do usuário): `variant/thread_support=false`
  no preset Web → sem `SharedArrayBuffer` → **sem necessidade de headers
  COOP/COEP**, servível por qualquer host estático (incl. o `ServeDir` do
  yggdrasil-web como está).
- Renderer: o projeto já tinha `renderer/rendering_method.web="gl_compatibility"`
  (Web exige Compatibility, não Forward+).
- Fix de export: `vram_texture_compression/for_{desktop,mobile}=false` — sem
  texturas, evita o erro silencioso "requer ETC2/ASTC" do validador de export.
- `run/main_scene` → `scenes/anatomy3d/anatomy_viewer.tscn` (o app web é o
  visualizador; lobby/games do Godot eram POC — o web arcade é servido pelo Rust).
- Servido em **`/anatomia`** (308 → `/static/anatomia/`), bundle em
  `yggdrasil-web/static/anatomia/` servido pelo `ServeDir` existente.

### Pipeline (reprodutível)

```bash
yggdrasil-godot/scripts/godot.sh install            # binário 4.5
yggdrasil-godot/scripts/godot.sh install-templates  # export templates 4.5 (~1.3 GB)
yggdrasil-godot/scripts/fetch-anatomy.sh            # malhas BodyParts3D
scripts/build-anatomy-web.sh                        # export → static/anatomia/
```

O bundle (`index.wasm` ~36 MB + `index.pck` ~31 MB) é **gitignored**; é gerado
pelo `build-anatomy-web.sh`. `godot.sh install-templates` adicionado.

## Acceptance

- `scripts/build-anatomy-web.sh` exporta o preset Web para
  `yggdrasil-web/static/anatomia/`.
- `GET /anatomia` redireciona (308) para `/static/anatomia/`; `index.html/js/wasm/
  pck` servem 200.
- O app Godot carrega no navegador (WebGL 2.0, Compatibility) e renderiza o corpo
  translúcido com o SNC dentro; UI de girar/zoom/pan/transparência presente.
- Bundle gitignored; `godot.sh check` segue verde (24 scripts).
- Verificado em Chrome real (Playwright) servido pelo yggdrasil-web local.

## Blast radius

Médio. Toca config do projeto Godot (preset Web, main_scene, vram) + 1 rota e 1
handler aditivos no `main.rs`. O `main_scene` agora é o visualizador 3D (o
desktop/`godot.sh run` abre o viewer por padrão). Bundle grande, mas fora do git.

## Deploy (Fly)

O bundle precisa estar na imagem deployada. Opções:
1. Rodar `build-anatomy-web.sh` no Docker build / CI (requer Godot + templates —
   pesado), ou
2. Versionar o bundle (commit / Git LFS) para a imagem servir direto.
Decisão pendente — fora do escopo desta task (que entrega o serving local
verificado).
