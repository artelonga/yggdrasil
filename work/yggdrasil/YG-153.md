GIVEN o YG já **escreve** notas pro CO (YG-149 `co_bridge_producer`), mas **não lê/importa
do CO** — um universo do CO não é navegável como vault no Mundo,

WHEN ligarmos a **federação inbound** (`co_bridge_inbound`): o YG **lê o conteúdo de um
universo do CO** (entradas/notas via a API do CO — vault/entries, read-only por padrão)
e o expõe como um **vault navegável no Mundo** ("importar do CO"), com **CRUD completo
onde permitido** (ler sempre; editar/criar grava de volta via o bridge do YG-149 quando
o usuário tem permissão no universo CO),

THEN o usuário **caminha por um universo do CO dentro do Mundo do YG** — lê o conteúdo
importado e, com permissão, edita/cria, sincronizando de volta (round-trip CO↔YG completo).

## Design
- **Inbound read** (`co_bridge_inbound`): consumir a API do CO (entries/vault read; o CO
  já serve isso) → materializar como `Room`/notas no Mundo (pasta=sala, nota=objeto),
  cacheando local. Respeitar visibilidade do CO (público/membro).
- **Mapa de identidade**: `universe_key` CO ↔ instância YG (contrato YG-138/CO-444);
  caminho de pasta CO ↔ sala YG (alinhar com CO-454 folder-sub-sala).
- **CRUD**: leitura sempre; **edição/criação** só com permissão no universo CO →
  grava de volta via o produtor do YG-149 (`co_bridge_producer`) / API de escrita do CO.
- **Conflito**: write-back é last-write por enquanto (resolução fina é follow-up com a
  presença YG-145); não perder dado — em conflito, preservar e logar.

## Acceptance
- [ ] `co_bridge_inbound` lê um universo do CO (entries/vault read) e o materializa como vault navegável no Mundo.
- [ ] Pasta=sala / nota=objeto derivados do conteúdo do CO; visibilidade do CO respeitada (não vaza privado).
- [ ] **Ler** sempre; **editar/criar** só com permissão → write-back via `co_bridge_producer` (YG-149).
- [ ] Mapa `universe_key` CO ↔ instância YG + caminho de pasta ↔ sala (alinha CO-454/CO-444).
- [ ] e2e Playwright: importar um universo CO → caminhar/ler → (com permissão) editar uma nota → confirmar write-back.
- [ ] `cargo test` + `clippy -D warnings` + `fmt` limpos. Não vazar conteúdo privado do CO.

## So that
Fecha o **round-trip completo CO↔YG**: o Mundo do YG não só publica pro CO, mas
**importa e edita** universos do CO — qualquer vault (CO ou YG) é um mundo caminhável.

## Não no escopo
- Resolução de conflito multiplayer fina (YG-145 presença, depois) · criar universo novo (YG-138).
