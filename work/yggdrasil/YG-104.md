## As
O time, que quer o CI do `main` verde e confiável.

## I Need
Reparar os **três** subsistemas que quebram o CI do `main` há semanas, para que o CI volte a
ficar verde e gatear de verdade.

## So That
O CI valida o que está sendo entregue, sem dívida pré-existente mascarando regressões nem
exigindo band-aids (`continue-on-error`/skip).

## Context

Descoberto ao tentar consertar o CI em 2026-06-06. O CI do `main` está **comprehensivamente
quebrado em 3 frentes independentes** — cada uma escondia a próxima (o run morria na 1ª antes
de chegar na 2ª). O manifesto de `universes/` já foi corrigido (`[workspace.package]` +
`[workspace.dependencies]` em `universes/Cargo.toml` — antes faltavam e quebravam o parse;
**esse fix está em main**). O que resta:

1. **`game-core` path dep — o bloqueador fundamental.** `yggdrasil-core` depende de `game-core`
   (via `[workspace.dependencies]` na raiz) que é `path = "../co/game-core"`. O CI só faz checkout
   do `yggdrasil`, então `../co/game-core` não existe → `cargo build` falha em "Build workspace"
   (`failed to load manifest for yggdrasil-core: No such file or directory`). É o **YG-38**
   ("pin game-core a git rev + drop path dep") que regrediu/nunca fechou. Sem isso, o CI **nunca**
   constrói o workspace — nem chega a rodar os 540 testes. Fix: pinar `game-core` a um git rev do
   repo `co` (ou clonar `co` no CI). **Maior alavancagem.**
2. **Crates WASM v1.0** (`universes/universe-{snake,tetris,invaders,pointset,poker}`) não
   compilam: referenciam `universe_sdk::{get_random,kv_load,kv_store}` (removidos/renomeados) e
   não satisfazem mais o trait `Universe`. "Universe platform" v1.0 (jogos embedados via wasmtime),
   não tocado desde a virada para conteúdo/mensageria. Prod roda nos blobs já buildados; é
   problema de **rebuild**, não prod-down.
3. **Lint GDScript do cliente Godot**: erros de parse pré-existentes em `poker/snake/tetris`
   (type inference, `GameBase`/`Card` ausentes).

**Estado do CI agora:** os experimentos de band-aid (continue-on-error/skip) foram **revertidos**
— `.github/workflows/ci.yml` está no original. O CI segue vermelho (como estava há semanas), mas
honesto e documentado aqui. O workspace mantido (`core`/`web`) passa **localmente** (540 testes +
fmt + clippy); só não roda no CI por causa do item 1.

## Acceptance

- **GIVEN** o CI (que só faz checkout do `yggdrasil`)  *(item 1 — bloqueador fundamental)*
  **WHEN** roda `cargo build --release`
  **THEN** o `game-core` resolve (pinado a um git rev do `co`, ou `co` clonado no CI) e o
  "Build workspace" passa — destravando os 540 testes + clippy no CI.

- **GIVEN** as crates `universe-*`  *(item 2)*
  **WHEN** rodar `bash scripts/build-universes.sh`
  **THEN** todas compilam para `wasm32` contra a API atual do `universe-sdk` (Universe trait + KV/random).

- **GIVEN** o lint Godot  *(item 3)*
  **WHEN** rodar `yggdrasil-godot/scripts/godot.sh check`
  **THEN** passa sem erros de parse.

- **GIVEN** os 3 itens acima verdes
  **WHEN** o CI roda no `main`
  **THEN** fica verde de ponta a ponta (sem `continue-on-error`/skip).

## Não no escopo
- Não é conteúdo/mensageria. Tarefa de manutenção do platform v1.0 + cliente Godot, sprint própria.
