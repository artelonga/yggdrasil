GIVEN o `/mundo` (Fatia 1 no ar, Fatia 2/3 chegando) **não tem documentação escrita**
nem **demonstração visual** — um visitante não entende o Mundo sem rodar,

WHEN gerarmos **GIFs via Playwright** das jornadas-chave (caminhar, entrar numa
pasta=sala, abrir/editar uma nota=objeto, drag-drop reposiciona) e **escrevermos a
documentação** do `/mundo` (controles, modelo pasta=sala/nota=objeto) e do **instance
model** (`InstanceStore`/`NoteStore`, `.md` canônico + `pos{room,x,y}`),

THEN a documentação tem **animações no DoD** e um leitor entende o Mundo e o modelo de
dados **sem executar nada**.

## Design
- **Playwright → GIF**: script que roda as jornadas e grava vídeo → converte pra GIF
  (ffmpeg/ ferramenta já usada), salvos em `docs/` (ou `static/`), referenciados na doc.
  Reusar o setup Playwright existente do repo.
- **Docs escritas** (`docs/mundo.md` + atualizar índice de arquitetura): controles
  (WASD/setas/clique, navegação por parede ↑entra/↓início/←→irmã), modelo **pasta=sala /
  nota=objeto**, os 5 temas, NPC (tutorial.md + Ollama), e o **instance model**
  (`InstanceStore`, `NoteStore`, frontmatter `pos{room,x,y}`, relação com o CO).
- **DoD**: os GIFs entram no critério de pronto das fatias do Mundo (prova visual).

## Acceptance
- [ ] Script Playwright gera GIFs de ≥4 jornadas (andar, entrar sala, abrir/editar nota, drag-drop).
- [ ] GIFs salvos no repo e **referenciados** na doc (renderizam no markdown/site).
- [ ] `docs/mundo.md`: controles + modelo pasta=sala/nota=objeto + temas + NPC, linguagem cliente (PT).
- [ ] Doc do **instance model** (`InstanceStore`/`NoteStore`/frontmatter `pos`) + relação com o CO.
- [ ] Link "Mundo" descobrível a partir de um índice existente.
- [ ] Sem segredo/binário pesado no git (GIFs otimizados); `cargo`/lint não regridem.

## So that
O Mundo fica **documentado e demonstrável** — pra coleta de feedback, onboarding e como
prova visual (GIF no DoD) das fatias, sem depender de rodar local.

## Não no escopo
- Tutorial-missões in-game (Fatia 5 restante) · NPC LLM endpoint · vídeo narrado.
