GIVEN o `/mundo` (v2.30.0) serve `static/universos/mundo-proto.html` com **dados mock**
(`static/universos/mundo/sample.js` dict `ROOMS`) e **não lê** o `InstanceStore`
(`yggdrasil-core/src/instance/store.rs`) nem o `NoteStore` (`.../note.rs`),

WHEN adicionarmos a view **"🌍 Mundo"** no instance view (ao lado de map/timeline/grafo
do YG-126) que **lê dados reais**: instância (`UniverseInstance`) → **pastas = salas** →
**notas = objetos** do `NoteStore`, alimentando o `engine.js` (data-agnóstico) com uma
`Room` derivada da estrutura real (sem `sample.js`),

THEN o usuário **caminha e entra/sai** num universo **real** (WASD/setas/clique, reusa
`engine.js`), e pisar numa **nota** abre o **conteúdo `.md` real** do `NoteStore`.

## Design
- Derivar `Room` do real: pasta (nó com filhos) → sala; nota `.md` (`pos{room,x,y}` no
  frontmatter quando existir, senão auto-layout) → objeto na grade; porta = pasta-filha.
- Nova view "🌍 Mundo" no instance view (YG-126) — endpoint que serve a página + um
  endpoint/JSON que entrega o grafo real da instância pro frontend (reusar o que o
  instance view já expõe; não duplicar leitura).
- `engine.js` **inalterado** (contrato data-agnóstico); só troca a fonte (`sample.js` →
  loader real). `proto.js` `onInteract`: nota → abre `.md`; porta → entra na sala-filha.

## Acceptance
- [ ] View "🌍 Mundo" no instance view lê `InstanceStore`/`NoteStore` (sem `sample.js`).
- [ ] Pasta→sala derivada da hierarquia real; nota→objeto com conteúdo `.md` real.
- [ ] Caminhar/entrar/sair funciona numa instância real (reusa `engine.js`, movimento atual).
- [ ] Pisar numa nota abre o `.md` real (read; CRUD de edição fica pra Fatia 3 / YG-149).
- [ ] e2e Playwright: abrir instância real → andar → entrar numa pasta → abrir uma nota.
- [ ] `cargo test` + `clippy -D warnings` + `fmt` limpos; sem mock no caminho real.

## So that
O `/mundo` deixa de ser protótipo mock e vira a **MVP navegável de um universo real** —
base pra manipulação direta (YG-149) e pro sync com o CO.

## Não no escopo
- Drag-drop/persistência (Fatia 3 / YG-149) · multiplayer (YG-145, depois) · Godot.
