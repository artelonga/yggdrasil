## As

A consumer of yggdrasil's API (frontend, CO renderer, external clients)

## I Need

A machine-readable OpenAPI 3.x spec served at `/openapi.json` (and ideally `/openapi.yaml`)

## So That

yggdrasil fits the "universal API + docs template" target — every repo in the ArteLonga ecosystem (CO via CO-226, quilombo-blog via QB-1, ArteLonga via AL-55, rfq-gateway via RFQ-27) exposes the same shape so CO's renderer treats them uniformly.

## Context

- **Principles:** §3 (static typing), §4 (reduced coupling — explicit contract)
- **Current state:** yggdrasil does **not** depend on `utoipa` yet (verified via `cargo tree | grep -i utoipa`). API surface is auth, lobby, single-player game routes (snake/tetris/invaders), poker (HTTP + planned WS via YG-41), me/universes, scores. Each handler returns typed `Json<T>` already (good baseline).
- **Scope:**
  1. Add `utoipa = "5.x"` to `yggdrasil-web/Cargo.toml` (matching the version CO and rfq use to keep cross-repo derive macros consistent).
  2. Add `#[utoipa::path]` derive to every handler in:
     - `auth.rs` (magic-link request/verify)
     - `api/me.rs`
     - `api/universes.rs`
     - `games/snake_routes.rs`, `tetris_routes.rs`, `invaders_routes.rs`
     - `games/poker_routes.rs` (post-YG-40 split)
     - `lobby_routes.rs`
  3. Add `#[derive(OpenApi)]` `ApiDoc` struct in `lib.rs` aggregating `paths(...)`.
  4. Add `GET /openapi.json` and `GET /openapi.yaml` routes in `main.rs`.
  5. Apply `#[derive(ToSchema)]` to all response types (`UserResponse`, `LobbyResponse`, `TableSnapshot`, etc.) — this is where the bulk of the edits land.

## Acceptance

- `curl -s http://localhost:PORT/openapi.json | jq '.openapi'` returns `"3.x"`.
- Spec includes paths for: auth (`/api/v1/auth/*`), me (`/api/v1/me*`), universes (`/api/v1/universes*`), all 4 game routes (`/api/v1/games/*`), lobby (`/api/v1/lobbies*`), poker (`/api/v1/poker/*`).
- Response schemas reference concrete types (no `serde_json::Value` in StartResponse / TickResponse — see **YG-42** prerequisite).
- Integration test asserts `/openapi.json` returns 200 and the spec has ≥20 paths.
- `docs/architecture/api-catalog.md` updated with pointer to `/openapi.json`.

## Blast radius

Medium — every handler gets a derive macro and every response struct gets `ToSchema`. Mechanical but touches ~25-30 sites. No runtime behavior change; pure type annotations + new route.

## Sequencing

Land **after** YG-39 (YggGame trait — game routes become parameterized, OpenAPI annotations apply uniformly) and **after** YG-42 (typed game state replaces `serde_json::Value` — schemas can be derived rather than `Object` placeholders). Both already in the backlog.

## Cross-repo

This is part of the "universal template" closure. After RFQ-27, YG-50, CO-226, QB-1, AL-55 ship, every ArteLonga ecosystem service exposes `/openapi.json` and CO can render any of them uniformly in the docs subuniverse view.
