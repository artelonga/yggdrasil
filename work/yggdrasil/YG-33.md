GIVEN as scenes compõem (YG-32), mas nada coordena entre elas além
de chamadas de método ad-hoc,
WHEN estabeleço o padrão de sinais autoritativos (servidor emite,
clientes ouvem) com mirror para event log append-only e modo replay,
THEN ganho event-sourcing nativo — todo estado da mesa é
reconstruível a partir do log, e mudanças são auditáveis sem
infraestrutura extra.

## Conceitos

```gdscript
# Padrão: intenção (cliente → servidor, validável)
@rpc("any_peer", "call_remote", "reliable")
func request_sit(seat: int) -> void: ...

# Padrão: autoritativo (servidor → todos, broadcast)
@rpc("authority", "call_local", "reliable")
func emit_seat_taken(seat: int, user_id: String) -> void:
    seat_taken.emit(seat, user_id)
```

UI assina **apenas** sinais autoritativos. Cliente nunca atualiza
estado canônico localmente — espera o servidor confirmar via emit.

## Critérios de aceitação

- [ ] `scripts/lib/signal_bus.gd` — autoload singleton com:
  - [ ] `register_authoritative(node: Node, signals: Array[String])` — registra que sinais devem ser logados.
  - [ ] Decorator/helper para diferenciar sinais autoritativos vs locais.
- [ ] Convenção de RPC documentada em `yggdrasil-godot/docs/SIGNALS.md`:
  - [ ] `request_*` — intenção (any_peer, reliable).
  - [ ] `emit_*` — autoritativo (authority, call_local, reliable).
  - [ ] Sinais GDScript regulares (`signal foo`) emitidos por `emit_*` para subscribers locais.
- [ ] Event log:
  - [ ] Cada sinal autoritativo serializado: `{timestamp, scene_path, signal_name, args}` em JSON-lines.
  - [ ] Diretório `out/events/<universe-id>/<session-id>.events`.
  - [ ] Flush a cada N=10 eventos OU 500ms (o que vier primeiro).
  - [ ] Append-only — nunca rewrite.
- [ ] Modo replay:
  - [ ] `godot --headless -- --replay <session.events>` — carrega scene, re-emite sinais na ordem, valida que estado final bate.
  - [ ] Teste: gerar 50 eventos, parar, replay, comparar `to_dict()` da raiz da scene.
- [ ] Recuperação após crash:
  - [ ] `kill -9` do server headless no meio de uma scene ativa.
  - [ ] Restart → server carrega último event log da universe, replay → scene volta ao estado pré-crash.
  - [ ] Teste integrado no CI (kill+restart via script).

## Não-objetivos

- Compactação do event log (snapshot + tail). Defer para pós-POC.
- Cifragem do event log. Não há PII em sinais de jogo.
- Migração de schema entre versões. Defer.
