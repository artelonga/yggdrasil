## As

A platform que quer um browser de anatomia **multiescala** (gross → núcleos →
EM connectome), com volumes hierárquicos recursivos e mídia anexável

## I Need

Provar e colocar no ar o stack **Neuroglancer** para a escala sub-anatômica:
um atlas de **núcleos subcorticais** renderizado como segmentos 3D selecionáveis,
servido pela plataforma em `/neuro`

## So That

Valida a direção (ver `project_neuro_multiscale` na memória): o viewer profundo
do neuro é Neuroglancer + Precomputed/OME-Zarr, não Godot. Godot fica como viewer
macro em `/anatomia`.

## Context

- **Dados**: Harvard-Oxford subcortical atlas (`sub-maxprob-thr25-1mm`, via
  `nilearn`) → **Precomputed** (cloud-volume + igneous local: segmentation raw +
  meshes + `segment_properties` com nomes). 21 núcleos. ~1.3 MB.
  `scripts/build-neuro-atlas.sh` + `scripts/convert_atlas.py` reproduzem (venv com
  cloud-volume/igneous/nilearn/nibabel). Dados gitignored.
- **Viewer**: Neuroglancer **hosted** embarcado em iframe
  (`static/neuro.html`), com chrome da plataforma. O bundle do pacote python é
  token-coupled (não roda standalone) → self-host do bundle standalone é o próximo
  passo. O estado do NG é montado p/ a origem atual (source Precomputed
  mesmo-domínio).
- **CORS**: `/static` ganha `CorsLayer::permissive()` p/ o NG (hosted, outra
  origem) buscar os dados Precomputed.
- **Rotas**: `/neuro` e `/universos/neuro` → `serve_neuro` (viewer NG);
  `/anatomia` continua o viewer Godot macro.
- ⚠ **Licença**: Harvard-Oxford é FMRIB/FSL (condições) — rever p/ uso comercial.

## Acceptance

- POC validado: NG renderiza os núcleos subcorticais como segmentos 3D
  selecionáveis (auto-mesh do labelmap) — confirmado em browser.
- `GET /neuro` → página com NG embarcado carregando o atlas Precomputed da própria
  plataforma; `/static/neuro-data/ho-sub/info` serve com `access-control-allow-
  origin: *`.
- Deploy no Fly; `/neuro` no ar em produção.
