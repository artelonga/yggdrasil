## As

Um usuário criando um universo novo

## I Need

**Templates** — instâncias-semente com paleta de blocos e dicas de render — para
começar de um esqueleto coerente em vez de uma grade vazia

## So That

Cada domínio (neuroanatomia, mapa de RPG, museu…) oferece um ponto de partida
opinativo; o editor sabe quais `block_type`s oferecer e como apresentá-los

## Context

Ler `docs/architecture/editor.md` (§ "Templates"). Mecanicamente três coisas:

```rust
pub struct Template {
    pub slug: String, pub title: String, pub description: String,
    pub seed: UniverseInstance,    // layers/projeção/grid/backgrounds pré-criados
    pub palette: Vec<PaletteItem>, // block_types permitidos + props default
    pub render_hints: serde_json::Value,
}
```

- Módulo `yggdrasil-core/src/instance/template.rs`. Templates registrados num
  registry estático simples (como `default_registry()` em `universes.rs`).
- `PaletteItem { block_type, default_props, schema: Option<...> }` — o `schema`
  opcional pode reusar `co/core/src/manifest.rs` (`ContentType`/`FieldType`) para
  validar `props`, mas isso é **defer**; v1 mantém `props` livre.
- Seeding: `POST /api/v1/instances?template=<slug>` (handler de YG-76 já aceita o
  param) clona o `seed` do template, atribui novo `id`/`owner`/timestamps.

### Endpoints

| Método | Rota | Função |
|---|---|---|
| GET | `/api/v1/templates` | listar templates (slug, title, description) |
| GET | `/api/v1/templates/{slug}` | detalhe: seed + palette + render_hints |

Esta story entrega a **mecânica** e ao menos **um template trivial** ("blank":
grade 2D vazia + paleta com `note`) para provar o caminho. O template
neuroanatomia completo é YG-80.

## Acceptance

- `yggdrasil-core/src/instance/template.rs` define `Template`, `PaletteItem`, um
  registry estático, e um template `blank`.
- Seeding: `POST /api/v1/instances?template=blank` cria uma instância a partir do
  seed (novo id/owner/timestamps), `template` field setado.
- `GET /api/v1/templates` e `GET /api/v1/templates/{slug}` implementados em
  `api/instances.rs` (ou submódulo `templates.rs`), wired no router.
- `?template=` desconhecido → 404; ausência de `?template=` → instância vazia
  default (comportamento já de YG-76).
- Testes: listar templates inclui `blank`; criar com `?template=blank` produz a
  estrutura do seed; slug inválido → 404.
- OpenAPI atualizado. `cargo test --workspace`, `clippy -D warnings`,
  `fmt --check` limpos.
- CHANGELOG `[Unreleased]`; bump minor.

## Blast radius

Médio — novo módulo em `yggdrasil-core` + 2 rotas read-only. Liga-se ao POST
existente (YG-76). Sem impacto em arcade/WASM/registry.
