GIVEN `game-core` está como path dep `../co/game-core` (frágil em CI),
WHEN substituo por dependência git com revisão fixa,
THEN o build é reprodutível em qualquer máquina, e atualizar para versão
nova do `co` é uma mudança consciente (commit que muda o rev).

## Critérios de aceitação

- [ ] `game-core = { git = "https://github.com/artelonga/co", rev = "<sha>" }` no `Cargo.toml`.
- [ ] Documentar em `docs/DEPENDENCIES.md`:
  - [ ] Como atualizar o rev do game-core (passos: testar localmente com path, copiar sha, abrir PR).
  - [ ] Critério de quando bumpar (security, bug fix relevante, feature pedida no roadmap).
  - [ ] Política para outras deps Rust: `cargo update --dry-run` mensal, security-only entre minor releases.
- [ ] CI workflow `.github/workflows/build.yml`:
  - [ ] `cargo fmt --check`.
  - [ ] `cargo clippy -- -D warnings`.
  - [ ] `cargo test --workspace`.
  - [ ] Cache `~/.cargo/registry` por SHA do `Cargo.lock`.
- [ ] Renovate config `renovate.json` ou Dependabot para alertar updates de patches.
