## As
Usuário cujas notas do Caderno do Ayvu Rapyta devem aparecer/editar no CO, como as notas de
instância — observáveis centralmente.

## I Need
Emitir as notas do Caderno na *federated bus* pelo path **instance-qualified**
`instances/<id>/notes/<slug>.md` via o producer staged (YG-93/97), batendo o contrato do
consumer **CO-389 exatamente** — instância canônica do Ayvu + convenção verso→slug estável.

## So That
No instante em que o CO landa o consumer (CO-389), o Caderno do Ayvu Rapyta **federa de
graça** — sem re-plumbing. Por isso o **contrato** (instância + slug + path) é a costura: vale
travá-lo agora, antes de YG-112/113.

## Context
A costura (doável **agora**, build+unit, decoplada de YG-112): uma instância canônica do Ayvu
(`AYVU_INSTANCE`) + `verso→slug` estável + `path = instances/<AYVU_INSTANCE>/notes/<slug>.md`
— idêntico ao `FederatedSource::Notes.path()` (YG-97). A **emissão ao vivo** ride no endpoint
de escrita do Caderno (YG-112) chamar `NoteStore::save` + `emit_note` (o producer YG-93/97 já
federa qualquer write de `NoteStore`). Isto é, YG-114 = travar o contrato + o adaptador
verso→nota; a federação viva acende quando YG-112 grava via `NoteStore`.

## Acceptance
- **GIVEN** uma nota de verso do Caderno  **WHEN** mapeada p/ federação
  **THEN** produz `path = instances/<AYVU_INSTANCE>/notes/<slug>.md`, `universe_key=yggdrasil`
  — batendo o contrato CO-389 (teste de unidade fixa o path/slug).
- **GIVEN** o adaptador verso→nota  **WHEN** uma nota é gravada via `NoteStore` (YG-112)
  **THEN** o producer staged emite `entry.*` no path acima (sem novo código de emissão).
- **GIVEN** o CO-389 vivo (futuro)  **WHEN** recebe  **THEN** o Caderno aparece no CO (E2E).

## Dependencies
- Producer + path instance-qualified **✅** (YG-93/97). Emissão viva: **YG-112**. E2E: **CO-389**.
