GIVEN o módulo `comunicacao` já tem léxico (`yggdrasil-core/src/comunicacao/lexicon.rs`,
`room.rs`, `store.rs`, `writeback.rs`) e o Mundo caminhável (YG-148) renderiza
`pasta=sala / nota=objeto`, MAS o léxico é só texto, preso a "idioma natural", sem
**som** e sem uma abstração que escale pra **qualquer sistema de símbolos**,

WHEN generalizarmos o léxico num **`LexiconPack`** — uma *linguagem* = **qualquer
sistema de símbolos com um léxico** (idioma natural, **música**, ou domínio como
"neuro") — e dermos a cada entrada uma **dimensão de áudio**, sendo a **MÚSICA a
primeira linguagem áudio-nativa** (a "palavra" É o som),

THEN qualquer pacote vira um léxico jogável e **soa**: notas/acordes da música tocam,
palavras de idioma ganham pronúncia — tudo **sintetizado em memória** (sem libs de
samples pesadas) e por contratos **engine-neutros** (o mesmo pacote alimenta o canvas
2D de hoje e um cliente 3D/voxel no futuro).

## Design
### LexiconPack (a abstração que escala)
- `LexiconPack { id, kind: language|music|domain, notation, theme, entropy_stats }`
  + entradas de léxico `{ term, gloss, refs[], relations[], examples[], audio? }`.
  Reusa `comunicacao/lexicon.rs` + `store.rs` + `NoteStore` (não duplicar; estender).
- **Música como pack**: "palavras" = notas (A4=440…), intervalos, acordes, motivos;
  "referência/significado" = o **próprio som** + teoria. **neuro/Hebraico** entram pelo
  mesmo tipo (kind=domain/language) — adicionar uma linguagem = soltar um pack.

### Camada de SOM (Web Audio, memory-light)
- `audio` por entrada, **sem arquivos de sample**:
  - **música** → params de síntese (freq/nota(s)/forma de onda/envelope ADSR) tocados
    por `OscillatorNode`/`GainNode` ao vivo.
  - **idioma** → pronúncia via IPA→Web Speech (`SpeechSynthesis`) ou um ref curto;
    fallback silencioso.
- Um único `AudioEngine` no front (lazy-init no 1º gesto do usuário — política de autoplay),
  pool de osciladores, **nada residente além do necessário**.

### Memory optimization (requisito do dono)
- Pacotes e entradas **lazy-load** (carrega ao entrar na sala, reusa YG-151); áudio
  **sintetizado** (não MB de samples); **cap de entradas residentes** + descarte LRU;
  contratos sem cópia desnecessária (referências/IDs, não blobs).

### Engine-neutral (rumo ao 3D "minecraft-like")
- O contrato **pack → mundo** e **entrada → objeto+som** é **agnóstico de renderização**
  (sem assumir 2D): posição abstrata, tipo, áudio. O canvas 2D atual é UM consumidor;
  documentar que um cliente 3D/voxel consome o MESMO contrato. Sem dívida que trave o 3D.

## Acceptance
- [ ] Tipo `LexiconPack` (kind language|music|domain) + schema de entrada com `audio?`, estendendo `comunicacao/lexicon.rs` (sem duplicar o léxico existente).
- [ ] **Pack de música** seed: escala + ≥3 acordes + 1 motivo, cada um com `audio` de síntese.
- [ ] **Som via Web Audio**: clicar/pisar numa nota toca o som (oscilador, **sem sample files**); acorde toca as vozes juntas.
- [ ] Pack de **idioma** carrega pronúncia (Web Speech/IPA) — prova de que a dimensão áudio serve linguagem E música.
- [ ] **Memory-light**: lazy-load por sala; áudio sintetizado; cap de entradas residentes (sem assets pesados no bundle/git).
- [ ] **Engine-neutral** documentado: contrato pack→mundo/entrada→objeto+som sem suposição 2D (caminho aberto pro 3D); `docs/` nota o contrato.
- [ ] e2e Playwright: carregar o pack de música → disparar uma nota → asserir que um nó de áudio foi criado/parametrizado (sem depender de hardware de som).
- [ ] `cargo test` + `clippy -D warnings` + `fmt` limpos.

## So that
"ÑE'Ẽ — The Lexicon Worlds" ganha sua **quilha**: qualquer linguagem (idioma, **música**,
neuro…) é um pack jogável que **soa**, leve de memória e pronto pra um cliente 3D —
a base pro mundo caminhável, quests e a camada Shannon (bits por linguagem) virem em cima.

## Não no escopo
- O jogo/quests completo + render walkable do pack (próxima tarefa) · cliente 3D/voxel
  (futuro; só não fechar a porta) · libs de sample/áudio pesadas · packs Hebraico/neuro
  completos (música é o seed; os outros entram pelo mesmo tipo depois).
