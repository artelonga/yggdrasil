GIVEN `game-core` expõe `WalletManager` com terminologia bancária,
WHEN crio uma fachada `yggdrasil_core::sementes::Sementes` que delega ao
`WalletManager` mas usa nomes do domínio Yggdrasil,
THEN APIs públicas e UI falam "sementes" e "saldo", enquanto o engine
permanece intocado.

## Referência em game-core

- `co/game-core/src/49a25f9f/e8d44050.rs` — `WalletManager` (não modificar).
- `co/game-core/src/49a25f9f/3549b002.rs` — `WALLET_TABLE` (não modificar).

## Critérios de aceitação

- [ ] `yggdrasil-core/src/sementes.rs`:
  - [ ] `pub struct Sementes { inner: WalletManager }`.
  - [ ] `pub fn saldo(&self, user_id: &str) -> Result<u64>`.
  - [ ] `pub fn creditar(&self, user_id: &str, qtd: u64) -> Result<()>`.
  - [ ] `pub fn debitar(&self, user_id: &str, qtd: u64) -> Result<u64>` — retorna saldo restante; erro `SaldoInsuficiente`.
- [ ] Erros tipados: `enum SementesError { SaldoInsuficiente, EngineError(_) }`.
- [ ] Mensagens em PT-BR.
- [ ] Não vazar `WalletManager` na superfície pública (só `Sementes`).
