GIVEN sentar em uma mesa hoje (YG-23) não custa sementes e ganhar uma
mão (YG-25) não credita sementes — a wallet existe (YG-10) mas está
desconectada,
WHEN integro `yggdrasil_core::sementes::Sementes` no `PokerTable::sit`
e `PokerTable::end_hand`,
THEN a mesa tem buy-in real, e o saldo de sementes flutua conforme
ganhos/perdas — exatamente como em `YggPoker` single-player (YG-9),
mas agora compartilhado entre humanos.

## Critérios de aceitação

- [ ] `PokerTable::sit(seat, user_id, sementes)`:
  - [ ] Debita `BUY_IN_SEMENTES` (default 1.000) da wallet via `Sementes::debitar`.
  - [ ] Recusa entrada com `SementesError::SaldoInsuficiente` se saldo < buy-in.
  - [ ] Saldo no chip stack do jogador é o buy-in (em "chips" 1:1 com sementes).
- [ ] `PokerTable::stand(user_id, sementes)`:
  - [ ] Credita o stack remanescente de volta na wallet via `Sementes::creditar`.
  - [ ] Se a partida está em andamento, o jogador faz fold automático antes do stand.
- [ ] `PokerTable::end_hand(sementes)`:
  - [ ] Distribui o pot ao vencedor (incrementa chip stack, não a wallet — só no `stand` vai pra wallet).
- [ ] Atualizar `poker_routes.rs::sit` para repassar `sementes: Arc<Sementes>` (state already injected).
- [ ] Frontend `poker.js`:
  - [ ] Mostra saldo atual de sementes no header (chama `/api/v1/me/sementes` no init).
  - [ ] Mostra chip stack atual de cada jogador sentado.
  - [ ] Bloqueia "sentar" se saldo < buy-in com mensagem PT-BR.
- [ ] Testes:
  - [ ] Sentar debita; levantar credita o restante; soma final == soma inicial menos perdas.
  - [ ] Saldo zero não consegue sentar.
  - [ ] Recarregar a página com partida em andamento mostra chip stack correto.

## Notas

Alinhar com YG-9: a mesma constante `INITIAL_SEMENTES = 10_000` e a
mesma chave de tabela `sementes` no `WalletManager`. Não criar wallet
paralela.
