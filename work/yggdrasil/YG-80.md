## As

A platform que quer demonstrar o editor com um caso real, educacional e
open-source

## I Need

O **template `neuroanatomia`**: uma instância-semente que renderiza o sistema
nervoso central dentro de um corpo humano, com **toggle de transparência**,
**landmarks anatômicos** e **conexões** entre eles, montado a partir de material
open-source

## So That

O editor genérico ganha seu primeiro template "não-arcade" de verdade, validando
que o formato data-driven expressa um domínio espacial rico **sem nenhuma adição
de schema** — e entregando um artefato demonstrável para a campanha

## Context

Ler `docs/architecture/editor.md` (§§ "Template neuroanatomia" e "Fontes
open-source de anatomia"). O caso expressa-se inteiramente no schema de YG-74:

- **Silhueta do corpo** = `Layer{kind:Background, opacity:1.0, background:Image}`.
- **Overlay do SNC** (cérebro + medula) = segundo `Layer{kind:Background,
  opacity:0.5}` empilhado acima; o **toggle de transparência** é o slider do player
  (YG-78) ligado a `layer.opacity` (persistível via PATCH `EditLayer{opacity}`).
- **Landmarks** = `Block{block_type:"landmark", pos, label, attachments}` numa
  layer `Blocks` (ex.: córtex frontal, cerebelo, tronco encefálico, medula) —
  cada um com anexo educacional (markdown/imagem/PDF).
- **Conexões** = `Connection{from, to, directed, label}` (ex.: tratos/vias
  neurais) renderizadas como linhas/setas.

### Fontes e licenças (ver doc para links)

- Começar com assets **CC0** (FreeSVG / SVG Silh — silhueta do corpo, contorno
  cérebro/medula) para evitar fricção de atribuição.
- Onde usar OpenStax (CC-BY 4.0) ou Wikimedia (CC-BY-SA), **carregar atribuição/
  licença** em `ContentRef`/`Block.props` e garantir que o player exibe o crédito
  (modelo de atribuição entregue nesta story).
- Tratos detalhados (SlicerDMRI/IIT) são fase posterior — v1 usa conexões
  ilustrativas entre landmarks, não dados de tractografia reais.

### Paleta neuroanatomia

`block_type: "landmark"` com props default (ícone, cor); opcionalmente
`block_type: "region"` (área anatômica) e `"annotation"` (nota livre).

## Acceptance

- Template `neuroanatomia` registrado em
  `yggdrasil-core/src/instance/template.rs` com `seed` contendo: 1 layer silhueta
  (Background opacity 1.0) + 1 layer SNC (Background opacity 0.5) + 1 layer Blocks
  com ao menos 4 landmarks de exemplo + ao menos 2 conexões; paleta com `landmark`
  (+ `region`/`annotation`); `render_hints` apropriadas.
- Assets open-source (silhueta + SNC) incluídos sob `assets/` ou referenciados,
  com **arquivo de atribuição/licença** (`docs/anatomia/ATTRIBUTION.md` ou
  equivalente) listando fonte + licença de cada asset.
- `ContentRef`/`Block.props` carregam campo de licença/atribuição; o player (YG-78)
  exibe o crédito ao abrir o anexo.
- `POST /api/v1/instances?template=neuroanatomia` cria uma instância funcional;
  abrir `/universos/instance/{id}` mostra silhueta + SNC, o slider de transparência
  revela/esconde o SNC, clicar num landmark abre seu conteúdo educacional, e as
  conexões aparecem entre os landmarks.
- Teste: criar via `?template=neuroanatomia` produz o seed esperado (contagem de
  layers/blocos/conexões); atribuição presente nos assets não-CC0.
- `cargo test --workspace`, `clippy -D warnings`, `fmt --check` limpos.
- CHANGELOG `[Unreleased]`; bump minor. `docs/architecture/editor.md` atualizado se
  o modelo de atribuição divergir do planejado.
