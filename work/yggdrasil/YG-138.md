## Feedback (usuário)
"Um universo criado por um usuário vira um universo novo em CO; o usuário pode
convidar quem quiser ou deixar público pra subscribe."

## Escopo
- Criar universo no yggdrasil (instância autorada, YG-126) → propaga ao CO como
  universo novo (parent_key = perfil/yuri-style), via bridge ou API do CO.
- Convites (lista de e-mails) e modo público-subscribable.
- Compor sobre o perfil universal (YG-137): "meus universos" = onde sou dono +
  onde tenho perfil.

## Bloqueado por (CO-side)
`parent_key` e criação de universo NÃO são API user-facing no CO (só seed.rs/
clone_ops.rs internos — confirmado na investigação nlp). Precisa de uma task CO
(ex.: CO-417 hardening) expondo: POST criar universo + visibility + convites.
Quando existir, o yggdrasil chama no commit do "criar universo".

## Acceptance (quando desbloqueado)
- GIVEN usuário cria universo no yggdrasil THEN aparece no CO como universo dele.
- GIVEN convite/público THEN terceiros acessam/subscribe conforme a visibilidade.
