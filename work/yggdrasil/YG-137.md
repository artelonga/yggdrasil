## Feedback (usuário)
Clicar num universo (mesmo os que não existem) → dois comportamentos: (1) link
para origem; (2) CTA "criar perfil neste universo". Por ora, um perfil universal
de usuário; cada universo compõe em cima dele.

## Entregue
- **Perfil universal** (`yggdrasil-core/profile.rs`): UM por usuário
  (`<root>/<user-slug>.json`), base (nome/bio/avatar) + mapa `universes` que cada
  universo compõe (props livres). Composição sobre herança, como nota↔tarefa.
  Normalização de usuário própria (sem o fallback "termo" do slugify de domínio).
- **API** (owner-only por JWT): `GET/PUT /api/v1/profile`,
  `PUT/DELETE /api/v1/profile/universos/{slug}` (criar/sair — idempotente, vale
  para slugs inexistentes: é o perfil que passa a existir, não o universo).
- **Catálogo** `/universos`: cada card com "↗ origem" (página/external_url/
  contribuição) e "✦ criar perfil aqui" (logado → PUT; senão → login).

## Teste
core 3 + api 2 + Playwright (perfil owner-only, card com os dois CTAs).
