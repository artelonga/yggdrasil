GIVEN a decisão de avaliar Godot como substrato dos universos
(arquitetura signals + scenes + lazy + multiplayer, ver epic YG-22),
WHEN crio o projeto `yggdrasil-godot/` Godot 4 com dois export presets
(HTML5/wasm para browser, Linux x86_64 headless para Fly) e plumbing
de build,
THEN o POC tem chão para crescer — uma scene "olá universo" carrega
tanto em browser quanto em servidor headless, sem nenhum jogo ainda.

## Por que é o primeiro task

YG-31..YG-35 (POC Godot) só faz sentido se a toolchain Godot ↔ Fly ↔
browser funcionar de ponta a ponta. Esta tarefa estabelece o piso
sem nenhuma lógica de jogo.

## Critérios de aceitação

- [ ] `yggdrasil-godot/project.godot` (Godot 4.5+, engine version pinada).
- [ ] Estrutura inicial:
  - [ ] `scenes/HelloUniverso.tscn` — Node2D com um Label "Olá universo".
  - [ ] `scripts/hello_universo.gd` — `func _ready(): print("hello from", multiplayer.is_server() ? "server" : "client")`.
  - [ ] `main.tscn` apontado em `application/run/main_scene` no project.godot.
  - [ ] `.gitignore` para `.godot/`, `*.tmp.tscn`, exports locais.
- [ ] Export presets (`export_presets.cfg`):
  - [ ] **Web** — HTML5, mobile=true, threads=true, custom HTML template com bootstrap mínimo.
  - [ ] **Linux/X11** — headless build (`--rendering-driver dummy --headless`).
- [ ] Script `yggdrasil-godot/scripts/build.sh`:
  - [ ] `godot --headless --export-release "Web" out/web/index.html`
  - [ ] `godot --headless --export-release "Linux/X11" out/headless/yggdrasil-godot`
  - [ ] Falha o script se Godot não estiver em `$PATH` com mensagem clara.
- [ ] Dockerfile (separado de yggdrasil-web/Dockerfile):
  - [ ] `yggdrasil-godot/Dockerfile` — stage 1 instala Godot 4.5 e roda build.sh; stage 2 (`debian:trixie-slim`) copia o headless binary.
  - [ ] Container exposes :3031 (porta dedicada Godot, separada da :3030 Rust).
- [ ] README.md em `yggdrasil-godot/` com:
  - [ ] Como abrir no Godot Editor local.
  - [ ] Como buildar os dois targets.
  - [ ] Como rodar o headless localmente.
- [ ] Não modifica `yggdrasil-core` nem `yggdrasil-web` (POC paralelo).
