## As

A maintainer of yggdrasil + co/game-core (pinned via YG-38)

## I Need

The diverged crates `universos/core` and `co/game-core` reconciled into a single canonical `co/game-core`

## So That

YG-38 pins yggdrasil to `co/game-core` at a known good rev (currently 268ea54). Anything still unique to universos's copy (notably `universo.rs` + improvements to the shared 49a25f9f/*.rs files) is silently lost. This reconciles, then advances the YG-38 pin.

## Context

- **Principles:** §4 (single source of truth — one canonical crate, not two)
- **Scope:** Files in universos/core/src/ NOT in co/game-core/src/:
- `universo.rs` — review + port if non-trivial

Files in co/game-core/src/ NOT in universos/core/src/:
- `mail.rs` — keep (newer)

Shared files that DIFFER between the two repos:
- `49a25f9f/04f8996d.rs`, `49a25f9f/3549b002.rs`, `49a25f9f/8a6cead4.rs`, `49a25f9f/mod.rs`
- `lib.rs`, `plugin.rs`

Process:
1. `diff -u universos/core/src/<file> co/game-core/src/<file>` per shared file. Identify universos-side improvements that should be preserved (heuristic: if universos has bug fixes / refactors that co/game-core lacks, port them).
2. Port `universos/core/src/universo.rs` into `co/game-core/src/universo.rs` (or fold its contents into an existing module if it duplicates).
3. Tag co/game-core 0.2.0 after the merge.
4. Advance yggdrasil's pinned rev in `yggdrasil/Cargo.toml` (currently `rev = "268ea54..."`) to the new co/game-core 0.2.0 commit.

## Acceptance

- `diff -rq universos/core/src co/game-core/src` returns only `Only in co/game-core/src: mail.rs` (no diffs in shared files).
- `co/game-core` tagged 0.2.0.
- yggdrasil/Cargo.toml advances pinned rev; `cargo test --workspace` still passes.
- CHANGELOG entries in both co and yggdrasil note the reconciliation.

## Blast radius

Medium — touches every diverged file in co/game-core; potential test churn if universo.rs introduces new types.
