## As

A platform operator and consumer of `/api/v1/universos`

## I Need

A versão real do `Cargo.toml` de cada universo aparece no `manifest.version`
exportado pelo WASM e no payload de `GET /api/v1/universos`

## So That

- Dashboard de telemetria (YG-62) consegue segmentar sessões por versão do
  universo (regression detection, A/B).
- Cliente exibe versão do universo no lobby.
- Auditoria de produção: "que versão do poker está em prod?" responde sem
  inspecionar o binário.

## Context

- O `universe-sdk::Universe::manifest()` hoje retorna `UniverseManifest`
  com `version: String` — mas cada universo hardcoda a string. Precisa virar
  uma constante derivada de `CARGO_PKG_VERSION`:
  ```rust
  // universe-sdk/src/lib.rs — macro helper novo:
  #[macro_export]
  macro_rules! pkg_version {
      () => { env!("CARGO_PKG_VERSION") };
  }
  ```
- Cada universo passa a usar `universe_sdk::pkg_version!()` em `manifest()`:
  ```rust
  fn manifest() -> UniverseManifest {
      UniverseManifest {
          name: "snake".into(),
          version: universe_sdk::pkg_version!().into(),
          api_version: 1,
          // ...
      }
  }
  ```
- O endpoint `GET /api/v1/universos` em `yggdrasil-web/src/universos_routes.rs`
  já lê o manifest do WASM; a versão propaga sozinha após a refatoração acima.
- `scripts/build-universes.sh` ganha um passo extra: ler `cargo metadata` e
  imprimir tabela `nome versão tamanho_KB` no fim da build, em vez de só
  `✅ X.wasm: NNNB`.

## Acceptance

- `universe_sdk` exporta o macro `pkg_version!()`.
- Cada um dos 6 universos consome `pkg_version!()` em sua implementação
  `Universe::manifest()`.
- `curl http://localhost:8080/api/v1/universos` retorna `version` igual à do
  `Cargo.toml` correspondente (verificável bumpando uma versão e rebuildando).
- `bash scripts/build-universes.sh` imprime ao final:
  ```
  Universe        Version   Size
  snake           1.0.0     142 KB
  tetris          1.0.0     156 KB
  ...
  ```
- Teste de integração em `yggdrasil-web/tests/`: para cada universe embedado,
  asserta que `version` é uma string semver válida.
- Sem mudança no formato JSON da API (mesmo campo `version`, agora com valor
  dinâmico — backwards-compatible).

## Blast radius

Médio — toca o SDK e os 6 universos. Mas é refator localizado (1 linha por
universo em `manifest()`).
