## As

A developer working on yggdrasil

## I Need

Um script `scripts/build-universes.sh` que compila todos os universos para WASM,
otimiza com `wasm-opt`, valida os budgets de tamanho, e um workflow GitHub Actions
que executa esse script antes de `cargo build`

## So That

O build é reproduzível — `cargo build` falha com mensagem clara se os `.wasm` não
existirem, e CI garante que nenhum universo excede seu budget de tamanho

## Context

- **Princípios:** §5 (build reproduzível), §7 (CI valida tudo)
- **Depende de:** YG-56 (SDK e crates existem), YG-57, YG-58 (universos existem)
- **Script `scripts/build-universes.sh`:**
  ```bash
  #!/usr/bin/env bash
  set -euo pipefail
  TARGET=wasm32-unknown-unknown
  OUT=yggdrasil-web/embedded
  mkdir -p "$OUT"
  UNIVERSES=(snake tetris invaders pointset poker vim)
  BUDGETS=(300000 300000 300000 200000 600000 250000)  # bytes
  for i in "${!UNIVERSES[@]}"; do
    U="${UNIVERSES[$i]}"
    cargo build -p "universe-$U" --target "$TARGET" --release
    SRC="target/$TARGET/release/universe_${U//-/_}.wasm"
    wasm-opt -O3 -s 100 "$SRC" -o "$OUT/$U.wasm"
    SIZE=$(wc -c < "$OUT/$U.wasm")
    BUDGET="${BUDGETS[$i]}"
    if [ "$SIZE" -gt "$BUDGET" ]; then
      echo "❌ $U.wasm: ${SIZE}B > budget ${BUDGET}B"
      exit 1
    fi
    echo "✅ $U.wasm: ${SIZE}B (budget: ${BUDGET}B)"
  done
  echo "Total: $(du -sh $OUT/*.wasm | tail -1)"
  ```
- **`yggdrasil-web/embedded/` em `.gitignore`** — artefatos de build, não versionados.
- **Fail-fast em `cargo build`:** `build.rs` em `yggdrasil-web` verifica se
  `embedded/*.wasm` existem; se não, emite `compile_error!` com mensagem:
  `"Run scripts/build-universes.sh before cargo build"`.
- **GitHub Actions** (`.github/workflows/ci.yml`):
  ```yaml
  - uses: dtolnay/rust-toolchain@stable
    with: { targets: wasm32-unknown-unknown }
  - run: cargo install wasm-opt --locked
  - run: bash scripts/build-universes.sh
  - run: cargo build --release
  - run: cargo test
  - run: cargo clippy -- -D warnings
  ```
- **Cache:** `~/.cargo/registry`, `target/` e `~/.cargo/bin/wasm-opt` cacheados
  por hash do `Cargo.lock` para não reinstalar em cada run.
- **Total budget gate:** script falha se `du -s embedded/` > 2MB.

## Acceptance

- `bash scripts/build-universes.sh` em ambiente limpo (sem cache) termina em < 3min
  e produz 6 arquivos `.wasm` em `yggdrasil-web/embedded/`.
- Cada `.wasm` está dentro do budget individual; total ≤ 2MB.
- `cargo build` sem `embedded/` falha com mensagem: `"Run scripts/build-universes.sh..."`.
- `cargo build` com `embedded/` presentes compila sem erro.
- GitHub Actions CI passa em push para `main` e PRs: build-universes → cargo build
  → cargo test → clippy.
- Modificar `universe-snake/src/lib.rs` para introduzir código que excede 300KB
  faz o CI falhar com "snake.wasm: NNNkB > budget 300000B".
