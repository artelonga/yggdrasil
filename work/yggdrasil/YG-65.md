## As

A contributor (humano ou co-auto)

## I Need

Cada universo tem seu próprio `CHANGELOG.md` no diretório `universes/universe-*/`,
seguindo Keep a Changelog 1.1 em PT-BR, com a versão atual já populada

## So That

Quando alterar `universe-poker`, eu sei onde escrever a nota de mudança sem
poluir o `CHANGELOG.md` do core. O changelog do core fica focado em mudanças
de plataforma (runtime, ABI, API, infra). Releases de universos individuais
ficam rastreáveis para auditoria

## Context

- Template (`universes/universe-snake/CHANGELOG.md`):
  ```markdown
  # Changelog — universe-snake

  Formato: [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/).
  SemVer.

  ## [1.0.0] — 2026-05-20

  ### Added
  - Migração inicial para WASM via universe-sdk ABI v1 (parte de YG-57).
  ```
- Sem entradas históricas pré-WASM (a migração para WASM é o "ponto zero"
  do versionamento independente).
- O CHANGELOG do **core** (`/CHANGELOG.md`) referencia bumps de universos
  apenas quando relevantes para a plataforma (ex.: "embed universe-poker
  v1.2.0 — fix bot AI deadlock").

## Acceptance

- Existe `CHANGELOG.md` em cada uma das 6 universes + `universe-sdk` (7 total).
- Cada um tem ao menos uma entrada de versão correspondente à versão declarada
  no `Cargo.toml` (YG-64).
- Conteúdo em PT-BR.
- `universes/README.md` (criar se não existe) lista os 6 universos com link
  para CHANGELOG e versão atual.
