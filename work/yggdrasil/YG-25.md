GIVEN o seating multiplayer funciona (YG-23), mas as cartas nunca são
distribuídas e o pot é sempre zero,
WHEN componho `PokerLobby` com `game_core::PokerGame`, gerencio o
ciclo pre-flop → flop → turn → river → showdown, e expõe ações
(call/raise/fold/check) via API,
THEN dois humanos sentados na mesma mesa jogam uma mão real, com pote,
blinds, e vencedor declarado.

## Referência em game-core

- `co/game-core/src/cd7ac4c6/fba2eac3/mod.rs` — `PokerGame`, `BettingRound`, `PokerAction`, `SelectedAction`.
- `PokerGame::players: Vec<Player>` — já é multi-player no modelo, falta orquestração assíncrona.
- `local_player_index` precisa ser substituído por "current actor" referenciado por user_id.

## Arquitetura

```
poker_lobby.rs (seating)  →  poker_game.rs (estado de partida)  →  PokerGame (engine)
                                    ↕
                            poker_routes.rs (HTTP)
```

`poker_game.rs` é novo. Não modifica `poker.rs` (single-player adapter,
permanece útil para futuras integrações tipo "treino contra bot offline").

## Critérios de aceitação

- [ ] `yggdrasil-core/src/games/poker_game.rs`:
  - [ ] `PokerTable` envolve `PokerLobby` + `PokerGame` + `current_actor: Option<String>`.
  - [ ] `start_hand(&mut self)` — só se ≥ 2 ocupantes (humano ou bot).
  - [ ] `act(user_id, action)` — valida turno, aplica, avança ronda se todos casaram.
  - [ ] Erros tipados PT-BR: `NaoEhSuaVez`, `AcaoInvalida`, `MesaSemJogadores`, `RoundEncerrado`.
  - [ ] Showdown declara vencedor via `EvaluatedHand` (já existe em game_core).
- [ ] `poker_routes.rs` extensão:
  - [ ] `GET /api/v1/poker/lobbies/{id}/hand` — estado público da mão (community cards, pot, current actor, próximos a falar).
  - [ ] `GET /api/v1/poker/lobbies/{id}/hole-cards` — apenas as cartas do usuário autenticado.
  - [ ] `POST /api/v1/poker/lobbies/{id}/action` body `{action: "call"|"raise"|"fold"|"check", amount?: u32}`.
- [ ] `poker.js` extensão:
  - [ ] Renderiza community cards, hole cards, pot, current bet.
  - [ ] Botões de ação aparecem só na vez do usuário.
  - [ ] Animação simples de carta sendo virada.
  - [ ] Banner "Sua vez!" + auto-scroll para a mesa.
- [ ] Remover badge "EM CONSTRUÇÃO" e seção placeholder de `poker.html` (ver YG-23).
- [ ] Testes:
  - [ ] 2 humanos completam uma mão até showdown (unit + integration).
  - [ ] Ação fora-da-vez retorna 409.
  - [ ] Fold da maioria encerra mão imediatamente.

## Não-objetivos

- Side pots (apostas all-in com diferentes stacks). Deferido para YG-31 se necessário.
- Histórico de mãos (já existe `HandRecorder` em game_core; deferir).
- Tournament mode (sit & go, blinds escalando).
