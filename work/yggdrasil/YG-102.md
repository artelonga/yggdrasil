## As
O time, querendo confiança ponta-a-ponta na mensageria antes de uma release.

## I Need
Um `scripts/e2e-comunicacao.sh` que exercita o fluxo real: login magic-link → criar sala → posicionar/publicar termo → revisar — contra um servidor de verdade.

## So That
Regressões no fluxo de léxico são pegas antes do release (paralelo ao `e2e-editor.sh` que já existe).

## Context
Pendência documentada. Molde: `scripts/e2e-editor.sh` (login real magic-link → criar de template → upload → EditOps → persistência → restart → re-leitura). Adaptar para as rotas `/api/v1/comunicacao/*` (`salas`, `salas/{id}` PATCH RoomEdit, `…/elementos/{eid}/publicar`, `revisao`, `revisao/nota`).

## Acceptance
- **GIVEN** um servidor rodando
  **WHEN** `bash scripts/e2e-comunicacao.sh`
  **THEN** executa login → cria sala (template yoruba/mbya) → publica um termo → registra revisão, validando cada passo via HTTP.
- **GIVEN** o write-back
  **WHEN** o termo é publicado
  **THEN** o script confirma o `.md` em disco no checkout (`COMUNICACAO_DIR`).
- **GIVEN** sucesso
  **WHEN** o script termina
  **THEN** sai 0; qualquer passo falho sai ≠ 0 com a resposta HTTP.
