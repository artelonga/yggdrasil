## As

A platform maintainer

## I Need

Cada `Cargo.toml` em `universes/universe-*/` declara `version`, `description` e
`license` próprios — sem herança de `workspace.package` do root do Yggdrasil

## So That

O ciclo de release de cada universo é independente do core. Atualmente
`universe-vim` herda `version.workspace = true` (que vem de `yggdrasil/Cargo.toml`),
enquanto os outros 5 têm `version = "0.1.0"` parado desde a criação. A próxima
vez que o yggdrasil bumpar para 1.0.1, o `universe-vim` herda silenciosamente
1.0.1, sem que nada nele tenha mudado

## Context

- Estado atual:
  - `universe-snake/Cargo.toml`: `version = "0.1.0"` (literal)
  - `universe-tetris`, `invaders`, `pointset`, `poker`: idem
  - `universe-vim/Cargo.toml`: `version.workspace = true` (herda do root yggdrasil)
  - `universe-sdk/Cargo.toml`: `version = "0.1.0"` (literal — manter)
- Versões inicial sugeridas (refletindo o estado real pós-v1.0):
  | Crate | Versão inicial | Razão |
  |---|---|---|
  | universe-snake | 1.0.0 | Estável desde YG-57 |
  | universe-tetris | 1.0.0 | Estável desde YG-57 |
  | universe-invaders | 1.0.0 | Estável desde YG-57 |
  | universe-pointset | 1.0.0 | Estável desde YG-57 |
  | universe-poker | 0.8.0 | Multiplayer ainda incompleto (YG-26 bot AI deadlock) |
  | universe-vim | 1.0.0 | Estável desde YG-58 |
  | universe-sdk | 0.1.0 | ABI v1 estável; bumpa para 1.0.0 só quando declarar contrato |
- `universes/Cargo.toml` (workspace) **não** deve ter `[workspace.package]` —
  cada crate declara o que precisa.

## Acceptance

- Cada `universes/universe-*/Cargo.toml` declara `version`, `description`,
  `license = "MIT"` (ou `"CC-BY-SA-4.0"` para Shandara) **literalmente**, sem
  herança.
- `universe-vim/Cargo.toml` deixa de usar `version.workspace = true`.
- `cargo metadata --format-version 1 --manifest-path universes/Cargo.toml` mostra
  6 valores distintos (ou iguais por coincidência, mas declarados isoladamente).
- `bash scripts/build-universes.sh` continua passando (size budgets inalterados).
- `cargo build --release` no root yggdrasil continua passando.

## Blast radius

Mínimo — só toca `Cargo.toml`. Sem impacto em runtime nem ABI.
