## As

A universe author (internal, for v1.0; external post-release)

## I Need

A `universe-sdk` Rust crate that defines the ABI v1 contract — host imports as
`extern "C"` declarations and the 4 required exports — plus helpers for string
passing across the WASM boundary

## So That

Each universe crate in `universes/` can depend on `universe-sdk` and implement
only its game logic, without manually managing WASM memory or host API bindings

## Context

- **Principles:** §1 (shared SDK = single definition of the contract)
- **Scope:** New crate `universes/universe-sdk/` with:
  - `[lib]` only, `crate-type = ["rlib"]` (linked into each universe cdylib)
  - `target = wasm32-unknown-unknown`
  - `Cargo.toml`: `opt-level = 'z'`, `lto = true`, `panic = "abort"`
  - **Host imports** declared as `extern "C"`: `wallet_get_balance`, `kv_get`,
    `kv_set`, `emit_event`, `now_ms`, `random_u64`, `request_hint`
  - **Required exports macro**: `universe_exports!(MySession)` expands to
    `create_session`, `tick`, `get_manifest`, `destroy_session`, `alloc`, `dealloc`
    with correct `#[no_mangle] pub extern "C"` signatures
  - `write_json` / `read_json` helpers: allocate in WASM heap, write JSON string,
    return ptr+len pair; host reads via `store.data()` memory
  - `UniverseManifest { name, version, api_version: u32, max_players, capabilities }`
    with `#[derive(Serialize)]`
  - Mock host for unit tests: `#[cfg(test)] mod mock_host` implements all imports
    as no-ops / fixed values so universo unit tests run on the native target
- See `docs/RELEASE-V1.md §Epic 2` for full ABI surface.

## Acceptance

- `cargo build --target wasm32-unknown-unknown -p universe-sdk` compiles with 0 warnings.
- `universe_exports!(MySession)` macro generates valid `extern "C"` exports that
  `wasmtime::Linker` resolves without symbol errors.
- `write_json` → `read_json` round-trip passes: host reads back identical string.
- Mock host enables `cargo test -p universe-sdk` to run on native target.
- A minimal "echo" universo using the SDK compiles to ≤ 50KB after `wasm-opt -O3`.

## Blast radius

Low — new crate in `universes/`, no changes to `yggdrasil-web` or `yggdrasil-core`.
Must not add `universes/` to the workspace `members` until YG-61 (build pipeline)
sets up the cross-compilation correctly; build it standalone for now.
