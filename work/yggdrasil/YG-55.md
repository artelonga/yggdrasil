## As

A yggdrasil server operator

## I Need

A `WasmRuntime` embedded in `yggdrasil-web` that loads universo `.wasm` binaries from
`include_bytes!()`, manages session lifecycle, and enforces compute budgets per tick

## So That

All universo logic runs in an isolated WASM sandbox — a misbehaving universo cannot
crash the server or access another session's memory

## Context

- **Principles:** §4 (single runtime host), §2 (no per-game special-casing)
- **Scope:** New module `yggdrasil-web/src/wasm_runtime.rs` with:
  - `wasmtime` dep (Cranelift, no Component Model yet — plain `Module` + `Linker`)
  - `WasmRuntime::from_embedded()` — pre-compiles all 6 modules at boot
  - `WasmSession` — wraps `Store<HostState>` + exported functions
  - Fuel set to `10_000_000` instructions per tick (hard limit, not soft)
  - Linker provides host imports: `wallet_get_balance`, `kv_get`, `kv_set`,
    `emit_event`, `now_ms`, `random_u64`, `request_hint`
  - `HostState` carries `user_id: Option<String>`, universe KV namespace,
    pending hint channel
- **No Component Model for v1.0** — plain WASM with manual `alloc`/`dealloc` exports
  for string passing. Component Model comes with user-upload (post-v1.0).
- `yggdrasil-web/embedded/*.wasm` are gitignored build artifacts; `build-universes.sh`
  produces them (YG-61). Build fails with clear message if they are absent.
- See `docs/RELEASE-V1.md §Epic 1` for full acceptance criteria.

## Acceptance

- `cargo add wasmtime --features cranelift` compiles without errors.
- `WasmRuntime::from_embedded()` loads all 6 `.wasm` modules in < 500ms on boot.
- `WasmSession::tick()` with a tight loop WASM returns `Err(FuelExhausted)` after
  ≤ 10M instructions — server continues serving other requests.
- Memory of session A is inaccessible from session B — verified by integration test
  that writes to a known address in session A and reads from session B (must not see it).
- `WasmSession::drop()` frees all WASM memory (no leak detectable via
  `store.data_mut()` after drop).
- `cargo test` passes; no `unsafe` outside of the WASM pointer helpers.

## Blast radius

Medium — new dependency (`wasmtime`, ~5MB compiled); no changes to existing routes or
game logic. `yggdrasil-core` untouched at this stage.
