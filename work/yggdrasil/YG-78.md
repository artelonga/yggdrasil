## As

A visitor abrindo um universo autorado

## I Need

Um **player genérico** que busca uma `UniverseInstance` por JSON e a renderiza —
layers z-ordenadas, projeção, opacity por layer, blocos, conexões — e abre os
anexos ao clicar num bloco

## So That

Instâncias autoradas são visualizáveis sem nenhum módulo WASM — é renderização de
dados estáticos, não simulação por tick

## Context

Ler `docs/architecture/editor.md` (§ "Runtime/serving"). **Nenhum WASM** — render
client-side puro. Segue o padrão do front-end existente: canvas + vanilla JS (sem
framework pesado, conforme CLAUDE.md), espelhando `static/universos/snake.js`.

- Nova página `yggdrasil-web/static/universos/instance.html` + `instance.js`.
- Servida por `serve_instance_player` em `main.rs` espelhando `serve_snake`
  (`Html(include_str!(...))`), rota `/universos/instance/{id}` (e
  `GET /api/v1/instances/{id}/play` apontando para a mesma página).
- O JS busca `GET /api/v1/instances/{id}`, então renderiza:
  - **Projeção:** `two_d_grid` (tiles planos) e `isometric`
    (`screen = ((x−y)·w/2, (x+y)·h/2)`). Começar suportando ambas; conteúdo
    neuroanatomia usa `two_d_grid` na v1.
  - **Layers** z-ordenadas (índice 0 = base), cada uma com `background` (imagem do
    anexo via `/attachments/{hash}`) e `opacity` aplicada.
  - **Blocos** desenhados na posição de grade, com ícone/cor de `props`.
  - **Conexões** como linhas/setas (respeitando `directed`) entre centros de bloco.
  - **Anexos:** clicar num bloco abre um painel — imagem inline, PDF em `<iframe>`/
    viewer, som via `<audio>`, markdown renderizado (reusar um render simples de
    markdown já presente, ou um mínimo).
  - **Atribuição:** se `ContentRef`/`props` tiver licença/atribuição, exibir crédito.

Read-only nesta story; o modo edição (paleta, drag, sliders persistidos) é YG-81.

## Acceptance

- `yggdrasil-web/static/universos/instance.html` + `instance.js` renderizam uma
  instância via `GET /api/v1/instances/{id}`.
- `serve_instance_player` em `main.rs` serve a página em `/universos/instance/{id}`;
  `GET /api/v1/instances/{id}/play` resolve para a mesma view.
- Layers z-ordenadas com `opacity` correta; backgrounds carregados via
  `/attachments/{hash}`.
- Blocos e conexões desenhados; clicar num bloco abre seus anexos (imagem/PDF/
  som/markdown) num painel; crédito de licença exibido quando presente.
- Ambas projeções renderizam (teste visual com uma instância iso e uma 2D).
- Acessível por teclado, alto contraste (consistente com o resto do front-end).
- Smoke: `/universos/snake` continua funcionando (nada de arcade tocado).
- CHANGELOG `[Unreleased]`; bump minor.

## Blast radius

Médio — nova página estática + 1 handler em `main.rs`. Sem impacto em arcade/WASM.
Depende do CRUD (YG-76) e dos anexos (YG-77).
