## As

A platform que quer ensinar anatomia em 3D interativo (não uma grade 2D)

## I Need

Um **visualizador 3D** no cliente Godot — orbitar (tilt/girar), zoom e pan sobre
um **corpo humano translúcido** com o **SNC (encéfalo + medula) visível por
dentro**, alternar a transparência do corpo, e clicar numa estrutura para
identificá-la — usando malhas anatômicas **open-source reais**

## So That

A experiência se aproxima de TeachMeAnatomy / atlas 3D interativos (o que o
usuário pediu), em vez do editor de grade 2D. Valida o pilar 3D do cliente Godot
sobre dados anatômicos reais e abertos.

## Context

Pivô a partir do editor 2D (YG-74..81): o substrato certo para "renderizar o SNC
dentro de um corpo transparente" é **3D**, não uma grade. Construído no cliente
Godot 4.5 (engine 3D nativa) — orbit camera, import de malha, materiais
translúcidos e raycast picking são nativos.

### Malhas (open-source real)

- **BodyParts3D** (DBCLS, **CC-BY-SA 2.1 JP**) — pele do corpo (FMA7163),
  encéfalo (FMA50801, 59 sub-malhas mescladas num OBJ), medula espinhal
  (FMA7647). As três compartilham o referencial de coordenadas do BodyParts3D,
  então o SNC já fica posicionado dentro do corpo.
- Baixadas/preparadas por `scripts/fetch-anatomy.sh` (não vão pro git por tamanho
  ~37 MB). Atribuição em `assets/anatomia/ATTRIBUTION.md`.

### Implementação

- `scenes/anatomy3d/anatomy_viewer.tscn` + `scripts/anatomy3d/anatomy_viewer.gd`:
  - Câmera orbital: arrastar = girar (yaw/pitch), scroll = zoom, botão direito =
    pan; auto-enquadra pela AABB combinada das malhas.
  - Corpo: material translúcido (alpha via slider — o toggle de transparência),
    `CULL_DISABLED` para ver o interior; encéfalo/medula opacos coloridos.
  - Click-to-pick: colisão trimesh nas estruturas internas (corpo sem colisão →
    clica-se através do corpo translúcido); raycast físico mostra o rótulo PT.
  - Eixo Z-up do BodyParts3D rotacionado para Y-up do Godot.
- `scripts/godot.sh check` valida o script (24 scripts no total).

## Acceptance

- `scripts/fetch-anatomy.sh` baixa o BodyParts3D e gera `body_skin.obj`,
  `brain.obj`, `spinal_cord.obj` em `assets/anatomia/`.
- `scenes/anatomy3d/anatomy_viewer.tscn` abre e renderiza o corpo translúcido com
  o encéfalo dentro da cabeça; o slider de transparência revela/esconde o corpo.
- Orbitar/zoom/pan funcionam; clicar numa estrutura interna mostra o nome PT.
- `assets/anatomia/ATTRIBUTION.md` credita BodyParts3D/DBCLS (CC-BY-SA 2.1 JP).
- Malhas geradas (`*.obj`) gitignored; `godot.sh check` passa.
- Verificado por render headless (3 frames: padrão, girado, corpo transparente).
