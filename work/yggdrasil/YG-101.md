## As
Falante/curador validando termos contribuídos por usuários.

## I Need
Um fluxo para promover um termo de `_users/<usuario-slug>/<slug>.md` (`seed_status: stub`) para `terms/<slug>.md` (`seed_status: reviewed`), após confirmação.

## So That
Termos contribuídos entram no **léxico curado** compartilhado, fechando o ciclo contribuir → revisar → publicar.

## Context
Pendência documentada. A escrita de contribuição já marca `seed_status: stub` (`comunicacao/lexicon.rs`). Falta: endpoint/admin de aprovação + mover/atualizar o arquivo (escrita atômica, atualizar frontmatter para `reviewed`, atualizar a fila de revisão). Auth de curador (admin token ou role).

## Acceptance
- **GIVEN** um curador autenticado e um termo `stub`
  **WHEN** aprova
  **THEN** o arquivo passa a `terms/<slug>.md` com `seed_status: reviewed`; o original em `_users/` é ligado/arquivado.
- **GIVEN** a fila de revisão
  **WHEN** o termo é promovido
  **THEN** a fila reflete o novo status (não reaparece como stub).
- **GIVEN** um não-curador
  **WHEN** tenta promover
  **THEN** 403.
