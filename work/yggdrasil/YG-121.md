## As
Yuri, querendo a federação **ao vivo** — um termo publicado numa sala aparece no `/agora` do CO em <1s.

## I Need
Setar os secrets do bridge nos dois apps e deployar; o **código está 100% pronto** (YG-118/119/120 +
CO-384/389/383/385). Só falta ligar via config + validar E2E. Sem mudança de código.

## Contexto (estado do código)
- yggdrasil emite o shape do CO-380 `Event` (YG-118), disca o socket real (YG-119) e faz o
  handshake `?source=&token=` que o CO-384 aceita (YG-120). Tudo **env-gated**: sem
  `YGG_CO_BRIDGE_URL`/`TOKEN` → no-op (estado atual de prod).
- CO-384 aceita por trust-list (`CO_BRIDGE_TRUSTED_SOURCES`) + token não-vazio. **Sem JWKS.**

## Runbook (executar — ordem importa: CO confia primeiro)

### 0) Gerar o token de bridge (compartilhado, opaco)
```bash
BRIDGE_TOKEN=$(openssl rand -base64 48)
```

### 1) Pré-flight E2E contra o CO-staging (sem tocar prod)
```bash
# co: confiar no source no STAGING
flyctl secrets set CO_BRIDGE_TRUSTED_SOURCES="yggdrasil.artelonga.com.br" -a co-artelonga-staging
# yggdrasil LOCAL apontando ao staging:
YGG_CO_BRIDGE_URL="wss://co-artelonga-staging.fly.dev/api/v1/events/bridge" \
YGG_CO_BRIDGE_TOKEN="$BRIDGE_TOKEN" \
YGG_CO_BRIDGE_NODE_ID="yggdrasil.artelonga.com.br" \
  cargo run -p yggdrasil-web
# publicar um termo numa sala → conferir co-staging /agora + universe comunicacao (<1s)
```

### 2) Prod — CO confia no source
```bash
flyctl secrets set CO_BRIDGE_TRUSTED_SOURCES="yggdrasil.artelonga.com.br" -a co-artelonga
```

### 3) Prod — yggdrasil liga o producer
```bash
flyctl secrets set \
  YGG_CO_BRIDGE_URL="wss://co.artelonga.com.br/api/v1/events/bridge" \
  YGG_CO_BRIDGE_TOKEN="$BRIDGE_TOKEN" \
  YGG_CO_BRIDGE_NODE_ID="yggdrasil.artelonga.com.br" \
  -a yggdrasil-artelonga
# (deploy/restart aplica os secrets)
```

### 4) Verificar (E2E ao vivo)
- Logs yggdrasil: `co-bridge producer ativo` + `bridge connected`.
- Logs/`/agora` do CO: `bridge.connected{source=yggdrasil...}`.
- Publicar termo numa sala → aparece no `/agora` do CO + na universe `comunicacao` (<1s).
- Editar uma nota de instância → idem (`entry.updated`, CO-383).

### Rollback (instantâneo, sem deploy de código)
```bash
flyctl secrets unset YGG_CO_BRIDGE_URL YGG_CO_BRIDGE_TOKEN -a yggdrasil-artelonga
# producer volta a no-op; nada mais federado.
```
