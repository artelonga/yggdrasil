## As

Um usuário anexando conteúdo (PDF/imagem/som/markdown/metadata) a um bloco

## I Need

Endpoints para **upload** (multipart) e **serve** de anexos, armazenados
**content-addressed por SHA-256**, retornando um `ContentRef` que o cliente
liga a um bloco via PATCH `AttachContent`

## So That

Conteúdo multiformato (a "compatibilidade de arquivos do co") fica disponível nos
universos autorados; dedupe automático por hash; links nunca quebram ao
mover/renomear instância

## Context

Ler `docs/architecture/editor.md` (§ "Anexos de conteúdo"). Reusa o `_blobs/` do
`InstanceStore` (YG-75) e o `write_bytes`/`read_bytes` do `ContentStore`.

### Rotas

| Método | Rota | Função |
|---|---|---|
| POST | `/api/v1/instances/{id}/attachments` | upload multipart → `ContentRef` |
| GET | `/api/v1/instances/{id}/attachments/{hash}` | servir bytes |

### Upload

- Multipart (axum `Multipart`). Streamar o body para um arquivo temp **calculando
  SHA-256 ao gravar** (crate `sha2`, já transitivamente presente; ou o helper de
  hash do `co/core/src/entry.rs`).
- Rename atômico para `_blobs/<shard>/<hash>` (shard = 2 primeiros chars do hash).
- Retornar `ContentRef { kind, hash, filename, mime, size }`. `kind` derivado do
  mime (allowlist). Cliente faz PATCH `AttachContent` para ligar ao bloco.
- **Allowlist de MIME** por `AttachmentKind` (image/png, image/svg+xml, image/jpeg,
  application/pdf, audio/mpeg, audio/wav, text/markdown, application/json) →
  fora da lista 415.
- **Cap de tamanho** (env, ex. `YGGDRASIL_MAX_ATTACHMENT_BYTES`, default 25 MB) →
  excedido 413.

### Serve

- Lê o blob por hash, seta `Content-Type` do mime gravado (persistido no
  `ContentRef` dentro do `instance.json`), `Content-Disposition` com `filename`,
  `Cache-Control: public, max-age=31536000, immutable` (seguro — content-addressed).
- Autorização: público se a instância está `published`, senão owner-only.

## Acceptance

- Os 2 handlers em `yggdrasil-web/src/api/instances.rs` (ou submódulo
  `attachments.rs`), wired no mesmo `instances_router`.
- Upload computa SHA-256, grava em `_blobs/<shard>/<hash>`, dedupa (upload do mesmo
  byte-stream duas vezes → mesmo hash, um só arquivo), retorna `ContentRef`.
- Allowlist de MIME e cap de tamanho aplicados (415 / 413 nos casos de borda).
- Serve devolve os bytes com `Content-Type`/`Content-Disposition`/`Cache-Control`
  corretos; respeita publish/owner.
- Teste: upload de um SVG pequeno → `ContentRef` com `kind:Image`; GET do hash
  devolve os mesmos bytes; mime não permitido → 415; arquivo > cap → 413; anexo de
  instância privada por não-owner → 403.
- `cargo test --workspace`, `clippy -D warnings`, `fmt --check` limpos.
- OpenAPI atualizado. CHANGELOG `[Unreleased]`; bump minor.

## Blast radius

Médio — endpoints aditivos no router de instâncias. Escreve em `data/instances/_blobs/`.
Sem impacto em arcade/WASM/registry. Depende de `InstanceStore` (YG-75); o ligamento
ao bloco usa o PATCH de YG-76.
