> **Wontfix (2026-05-23):** modelo pré-WASM (universos como recursos por
> usuário). v1.0 entregou `GET /api/v1/universos` (YG-60) com universos
> embedados globais. Filtro per-user só faz sentido quando user-uploaded
> universos (v2.x) existirem — re-abrir como YG novo nesse momento.


GIVEN o usuário está autenticado (YG-11),
WHEN faço `GET /api/v1/me/universos`,
THEN recebo a lista dos universos que o usuário criou ou se inscreveu, com
metadados (slug, nome, visibilidade, papel do usuário, tile-grid resumido).

## Critérios de aceitação

- [ ] Endpoint em `yggdrasil-web/src/api/me.rs` ao lado de `/me/sementes`.
- [ ] Resposta:
  ```json
  {
    "universos": [
      {
        "slug": "snake",
        "nome": "Snake",
        "visibilidade": "publico",
        "papel": "jogador",
        "ultima_visita": "2026-05-09T..."
      }
    ]
  }
  ```
- [ ] Filtros: `?visibilidade=publico|privado`, `?papel=criador|jogador`.
- [ ] Paginação cursor-based (`?cursor=<id>&limite=50`).
- [ ] Sem N+1: uma query SQL.
- [ ] Documentado no OpenAPI.
