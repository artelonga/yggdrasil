GIVEN a API pública precisa identificar o usuário,
WHEN espelho o fluxo de login por email do `co-web` (request code → verify
→ JWT) no Yggdrasil,
THEN endpoints `/api/v1/me/*` aceitam `Authorization: Bearer <jwt>` e
falham com 401 sem token.

## Referência em game-core / co

- `co/co-web/src/auth.rs` — `Claims`, `UserId` extractor.
- `co/co-web/src/game_routes.rs:17-26` — constantes (TTL, rate limit).
- `co/co-web/src/game_routes.rs` — handlers `request_code` / `verify_code`.

## Critérios de aceitação

- [x] `yggdrasil-web/src/auth.rs` com extractor `Claims`/`UserId` compatível.
- [x] `POST /api/v1/auth/code` — pede código por email (rate limit 3/15min).
- [x] `POST /api/v1/auth/verify` — valida código, retorna JWT (TTL 7 dias).
- [x] JWT secret de env var `YGGDRASIL_JWT_SECRET`; fail-fast no boot se ausente.
- [x] `MailProvider` reusado de `game_core::mail`. Default em dev: `LogMailProvider`.
- [x] Mensagens de erro em PT-BR.
