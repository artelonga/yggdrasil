## As

A developer trabalhando no cliente/editor Godot

## I Need

Uma integração CLI que **provisiona** o Godot 4.5 headless e **valida** todo o
GDScript sem precisar abrir o editor — rodável localmente e no CI

## So That

O editor Godot (YG-73) e o cliente arcade existente têm os scripts verificados a
cada push, em vez de só descobrir erros de parse ao abrir o editor manualmente.
Antes desta task não havia binário Godot provisionável nem lint headless — o
README mandava "instale você mesmo".

## Context

`scripts/build.sh` (exports) exigia um `godot` no `$PATH` que ninguém provisiona,
e não havia validação de GDScript. Esta task adiciona `scripts/godot.sh`:

- `install` — baixa o binário Godot 4.5 headless da release oficial para o cache
  gitignored `.godot-bin/` (Linux x86_64/arm64 + macOS universal). Em macOS,
  remove a quarentena do Gatekeeper (`xattr`) e assina ad-hoc (`codesign`) —
  senão o binário baixado é morto com SIGKILL.
- `bin`/`version`/`import`/`editor`/`run` — utilitários de dev.
- `check` — valida GDScript via harness SceneTree `scripts/dev/lint.gd` que
  carrega cada `.gd` em **contexto de runtime** (autoloads registrados). Isso
  evita falsos positivos de "Identifier not found: SignalBus/ApiClient/…" do
  `--check-only` por arquivo, e cobre scripts não referenciados por cena (como
  os do editor). A fonte da verdade é o grep do log (Godot loga `SCRIPT ERROR`
  mas não retorna exit≠0 em erro de parse).

Resolução de binário compartilhada por `godot.sh` e `build.sh`:
`$GODOT_BIN` → `.godot-bin/` → `godot`/`godot4` no `$PATH`.

CI: novo job `godot` em `.github/workflows/ci.yml` roda `install` + `check`
(binário cacheado por `actions/cache`).

### Bugs reais encontrados pelo `check` (corrigidos aqui)

O lint revelou três quebras pré-existentes sob Godot 4.5 (não introduzidas pelo
editor novo):

1. `scripts/autoloads/api_client.gd` — `func _get(...)` colide com o virtual
   `Object._get()` → erro de parse. Renomeado para `_http_get`/`_http_post`
   (callers internos atualizados; API pública `start_game`/`send_game_input`
   intacta).
2. `scripts/games/invaders/invaders_game.gd` — `var color :=` de índice de array
   não-tipado não infere tipo. Anotado `var color: Color =`.
3. `scripts/games/tetris/tetris_game.gd` — mesmo padrão no ternário de cor.

## Acceptance

- `scripts/godot.sh` com subcomandos `install/bin/version/import/check/editor/run`.
- `scripts/dev/lint.gd` carrega todos os `.gd` em contexto de runtime.
- `.godot-bin/` no `.gitignore`.
- `build.sh` compartilha a resolução de binário (respeita `$GODOT_BIN` + cache).
- `./scripts/godot.sh install && ./scripts/godot.sh check` passa verde com os 23
  scripts válidos; injetar um erro de parse num script (mesmo não referenciado)
  faz o `check` sair com código 1.
- Job `godot` adicionado ao CI.
- README documenta o fluxo CLI.
- Os 3 bugs reais de GDScript sob 4.5 corrigidos.

## Blast radius

Baixo-médio — adiciona tooling (scripts) + 1 job de CI. Os fixes em
`api_client.gd`/`invaders`/`tetris` são internos e desbloqueiam o cliente Godot
sob 4.5 (sem mudar a API pública dos autoloads/jogos). Nenhum código Rust tocado.
