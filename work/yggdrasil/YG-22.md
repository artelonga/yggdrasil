GIVEN o universo Pôquer existe como adapter single-player (YG-9) e como
infraestrutura de seating com bot (YG-23, já entregue fora-de-board no
deploy de 2026-05-12),
WHEN entrego as 7 sub-tarefas abaixo,
THEN o universo Pôquer atinge paridade com Snake/Tetris/Invaders no
quesito "jogável end-to-end", mas com a complexidade adicional de ser o
primeiro universo multiplayer da plataforma.

## Por que é um epic, não uma tarefa

Pôquer multiplayer cruza três fronteiras que os outros universos não
cruzam:
- **Auth obrigatório** (lobbies só para logados, ver YG-23).
- **Estado compartilhado entre clientes** (precisa de polling ou WS, ver YG-28).
- **Wallet de sementes integrado** (buy-in/cash-out por partida, ver YG-26).

Quebrar em tarefas individuais permite landing incremental — cada
sub-tarefa fecha em um commit testável.

## Arquitetura

Este epic instancia o padrão de [`docs/ARQUITETURA-UNIVERSOS.md`](../../docs/ARQUITETURA-UNIVERSOS.md).
Toda mudança aqui usa escopo `(YG-<n>, poker)` em commits, e o release
final (YG-30) é `0.8.0` — minor bump justificado pelo conjunto de `feat`s.

```
yggdrasil-core/src/games/
├── poker.rs             ← single-player adapter (YG-9, mantido)
└── poker_lobby.rs       ← multiplayer seating (YG-23)
       └─ futuramente ↓
          ├── poker_game.rs    ← dealing/betting (YG-25)
          └── poker_bot.rs     ← AI random (YG-26)

yggdrasil-web/src/games/
└── poker_routes.rs      ← /api/v1/poker/* (YG-23, expandido em YG-25/26)

yggdrasil-web/static/games/
├── poker.html           ← shell + login CTA (YG-23)
└── poker.js             ← seating + polling (YG-23, expandido em YG-25/28)
```
