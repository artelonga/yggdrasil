## As

A player of snake, tetris, invaders, pointset, or poker

## I Need

Each of the 5 existing game adapters (`YggSnake`, `YggTetris`, `YggInvaders`,
`YggPoker`, pointset) rewritten as self-contained WASM crates under `universes/`,
with the existing server routes acting as aliases

## So That

All game logic runs inside the WASM sandbox (fuel-limited, memory-isolated),
`yggdrasil-core` can be removed from the server binary, and each universo can be
independently versioned and eventually open-sourced

## Context

- **Principles:** §4 (single canonical implementation per universo), §6 (encapsulate in folder)
- **Depends on:** YG-55 (WasmRuntime), YG-56 (SDK)
- **Scope:** Create `universes/universe-{snake,tetris,invaders,pointset,poker}/` each with:
  - `Cargo.toml`: `[lib] crate-type = ["cdylib"]`, `opt-level='z'`, `lto=true`, `panic="abort"`
  - `src/lib.rs`: implements `Session` using game logic from `game-core` (dep on
    `game-core = { git = "...", rev = "..." }` — same rev as current yggdrasil pin)
  - Exports via `universe_exports!(MySession)` macro from SDK
  - Game state serialized as JSON (same schema as current HTTP response bodies —
    no breaking change for browser clients)
  - Score emitted via `emit_event("score", ...)` — host persists to `scores` table
  - Poker: `kv_set`/`kv_get` for table snapshots (replacing `poker_persistence.rs`)
- **Migration strategy (additive, no breaking change):**
  1. Implement universo WASM crates (routes not changed yet)
  2. `WasmRuntime` serves them at `/api/v1/universos/{id}/sessoes` (YG-60)
  3. Env flag `YGGDRASIL_WASM_ENABLED=1` routes legacy URLs through WASM
  4. After validation: remove native handlers from `yggdrasil-web/src/games/`
- **Size budgets** (after `wasm-opt -O3`):
  snake ≤ 300KB, tetris ≤ 300KB, invaders ≤ 300KB, pointset ≤ 200KB, poker ≤ 600KB
- See `docs/RELEASE-V1.md §Epic 3` for full acceptance criteria.

## Acceptance

- Each `universe-{U}.wasm` compiles and passes size budget (CI gate in YG-61).
- `WasmRuntime::new_session("snake", "{}")` returns Ok; 10 ticks with valid input
  return valid JSON state for each of the 5 universos.
- Tick with invalid input returns `{ "error": "..." }`, session remains alive.
- Legacy route `GET /api/v1/games/snake/start` returns identical response format
  before and after migration (tested with snapshot test).
- Poker table state survives server restart via WASM `kv_set`/`kv_get`
  (replaces `poker_persistence.rs` — same behavior, different implementation).
- `cargo test` passes; existing 77 tests continue to pass.
- `yggdrasil-core` crate dependency removed from `yggdrasil-web/Cargo.toml`
  after step 4 is validated.

## Blast radius

High — touches every game adapter and eventually removes `yggdrasil-core` from the
server binary. Mitigated by additive migration strategy and `YGGDRASIL_WASM_ENABLED`
flag for staged rollout.
