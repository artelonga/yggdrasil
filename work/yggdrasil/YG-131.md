## As
Quem cria: um só conceito (nota), formas emergentes.

## I Need
Unificação completa por composição:
- **Todo nó do grid é uma nota.** 1ª linha do composer = TÍTULO (nome do
  artigo; slug extraído dele — já é assim). `nome/` cria nota de corpo vazio.
- **Pasta = render**, não tipo: nota **sem corpo** renderiza 📁 (pasta);
  nota **com corpo e filhos** renderiza como **index.html** (índice: corpo +
  listagem dos filhos no inspetor); nota com corpo sem filhos = 📝 artigo.
  Ícone é computado no render, nunca gravado como verdade.
- **Arrastar sobre QUALQUER nó = aninhar** (`parent`) — gesto espacial é
  hierarquia, como filesystem. Referências são gesto textual: wikilinks
  (e o botão 🔗 para quem preferir).
- Inspetor unificado: corpo renderizado (se houver) + "conteúdo da pasta"
  (filhos clicáveis, se houver) + editar/status — o mesmo para tudo.
- Legado: blocos `block_type: pasta` antigos (sem nota) seguem renderizando
  e aninhando como antes.

## Acceptance
- GIVEN `projetos/` no composer THEN nota "projetos" criada (corpo vazio,
  slug projetos), renderiza 📁; ganhar corpo depois mantém os filhos (vira índice).
- GIVEN nota só-título THEN renderiza 📁 até ganhar corpo (vira 📝).
- GIVEN drag de um nó sobre outro THEN vira filho (parent), qualquer alvo.
- GIVEN nota com corpo E filhos THEN inspetor mostra corpo + filhos (índice).
