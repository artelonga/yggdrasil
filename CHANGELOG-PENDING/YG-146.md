## YG-146 — EPIC — Mundo walkable: lobby/universo como jogo 2D (Tibia + Gather)

Completa o EPIC do Mundo walkable com os três itens restantes:

### Tutorial como missões (2 páginas)

Overlay `#missao` de primeira-vez com 2 páginas progressivas:
- **Página 1 — Boas-vindas**: explica movimento (WASD/setas/click) e entrar em salas.
- **Página 2 — Drag-drop**: explica arrastar notas com animação CSS demonstrando o gesto
  (nota deslizando + cursor mão, loop infinito). Gatilhos: (a) 800 ms após o boot da
  primeira visita; (b) ao pisar na primeira porta da sessão (entry point para novos
  usuários que chegam direto numa pasta).
  Marcado `done` em localStorage (`mundo_missao_v1`) — não re-aparece em visitas
  subsequentes. Fecha com Esc ou "Pular tutorial".

### Endpoint Rust `POST /api/v1/npc`

Novo handler em `yggdrasil-web/src/api/npc.rs`:
- Body: `{ q: string, universo?: string }` → `{ answer: string, source: "llm"|"deterministic" }`.
- `OLLAMA_URL` + `OLLAMA_MODEL` (env-gated): chama `POST {url}/api/chat` com
  `tutorial.md` embutido como system prompt + `universo` como contexto; timeout 15 s.
- Fallback determinístico: keyword-match normalizado (strip acentos) sobre os tópicos
  do `tutorial.md` — funciona sem backend, mesma lógica já presente no JS do protótipo.
- `tutorial.md` embutido via `include_str!` (deploy-safe, sem path em runtime).
- Testes unitários: parse de tópicos, resposta de movimento, fallback sem match, normalize.

### GIF Playwright (DoD)

`e2e/mundo-gifs.mjs` agora gera 6 jornadas em `docs/mundo/`:
`andar`, `entrar_sala`, `abrir_editar_nota`, `drag_drop`, **`tutorial_missoes`**, **`npc`**.
O script pre-popula `localStorage` (`mundo_missao_v1`) para jornadas que não devem ver o
tutorial, evitando que o overlay bloqueie cliques nas outras gravações.

### Why

O protótipo do Mundo já exercitava o fallback determinístico do NPC via JS; este PR
fecha a integração server-side (Ollama) e garante que novos usuários recebam orientação
contextualizada ao primeiro contato (missões 1ª vez + NPC com LLM opcional). Os GIFs
de `tutorial_missoes` e `npc` completam a documentação visual exigida pelo DoD.
