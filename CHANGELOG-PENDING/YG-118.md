## YG-118 — Congelar o wire + alinhar o producer ao contrato CO-384/389 (envelope/payload/path/eventos de sala)

Reescrito `yggdrasil-web/src/co_bridge_producer.rs` para emitir o envelope canônico
`BridgeMessage::Event { federated: FederatedEvent { event: CoEvent { … } } }` (mirrors
CO-380/CO-384) em vez da flat `FederatedEvent` anterior. Wire congelado:

- **Termos de léxico** (`universe_key=comunicacao`): path agora inclui `_users/<user-slug>/`
  para casar o filtro do consumer CO-389. `FederatedSource::Comunicacao` passou a carregar
  `user_slug` derivado via `slugify(room.owner)`.
- **Notas de instância** (`universe_key=yggdrasil`): mantido `instances/<id>/notes/<slug>.md`,
  acrescentado `body_hash` (SHA-256 hex) ao payload.
- **Atividade de sala**: `Presence` renomeado para `UserJoined`; adicionado `TermContributed`
  (emitido em `publicar_elemento`); `Unpublished` aposentado do wire (mapeado como
  `yggdrasil.sala.published { published: false }`).
- **`ObservabilityEvent.encode()`** produz `BridgeMessage` em vez do struct plano anterior.
- **`co_bridge_inbound.rs`** atualizado para ler campos via `event.event.*` e
  `event.event.payload["field"]` (novo shape aninhado).
- **`comunicacao_routes.rs`**: `emit_terms` passa `user_slug`; `publicar_elemento` emite
  `RoomActivity::TermContributed` após contribuição.
- Adicionado `sha2 = { workspace = true }` em `yggdrasil-web/Cargo.toml`.

### Why

Sem este alinhamento, YG-119 (dial real) conectaria o socket mas zero eventos seriam
federados: o consumer CO-389 filtra por `_users/` no path e desserializa `TermPayload`
com `body_hash` — campos ausentes na wire anterior.
