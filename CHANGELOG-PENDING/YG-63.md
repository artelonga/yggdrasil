## YG-63 — Versionamento independente por universe

Cada crate em `universes/` passa a ter SemVer, CHANGELOG e convenção de tag git
próprios, desacoplados do ciclo de release do core.

- **YG-64** — `universes/universe-*/Cargo.toml` declara `version`/`description`/
  `license` literalmente, sem herança de `workspace.package`. Versões iniciais:
  snake/tetris/invaders/pointset/vim `1.0.0`, poker `0.8.0`, sdk `0.1.0`.
  `universe-vim` deixou de usar `version.workspace = true`; `[workspace.package]`
  removido do `universes/Cargo.toml`.
- **YG-65** — `CHANGELOG.md` por crate (6 universos + sdk = 7), Keep a Changelog
  PT-BR; `universes/README.md` com catálogo, versões e links.
- **YG-66** — `universe-sdk` exporta o macro `pkg_version!()`;
  `scripts/build-universes.sh` imprime tabela `Universe / Version / Size` ao
  final; `GET /api/v1/universos` expõe a `version` SemVer de cada universo
  (sincronizada com o `Cargo.toml` do crate) + teste de validação semver.
- **YG-67** — `docs/UNIVERSE-VERSIONING.md` (regras de bump universo vs. core,
  formato de tag `universe-<id>-v<X.Y.Z>`, workflow end-to-end); `CLAUDE.md`
  (raiz + `work/yggdrasil/`) referenciam o documento.

Parcial: a wiring de `pkg_version!()` dentro de `Universe::manifest()` de cada
universo fica para YG-104 — os crates WASM atualmente não compilam contra a ABI
atual (não implementam o trait `Universe`), então a `version` da API é mantida
em sincronia manual por ora.
