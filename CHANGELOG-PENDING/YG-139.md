## YG-139 — EPIC — Framework NLP de corpus: documento como árvore, corpora como álgebra (DuckDB)

Framework NLP de corpus implementado com DuckDB embarcado (`corpus_nlp.rs`). Índice montado em memória no boot a partir do canônico (corpus JSON + léxicos) — derivado, reconstruível.

Corpora: `ayvu-rapyta` (transcrição do Ayvu Rapyta com contagem de ocorrências), `mbya-lexico` (4.837 termos com glosas PT), `yoruba-lexico`.

Rotas HTTP:
- `GET /api/v1/corpus` — lista corpora disponíveis (nome, idioma, total de termos)
- `GET /api/v1/corpus/{nome}/freq` — frequência por popularidade (`?limit=50`)
- `GET /api/v1/corpus/compare?a=&b=&mode=` — join cross-linguístico via pivô português (inner = só termos com equivalente; left = todos de A)

Página `/universos/corpus-lab` com seletor A/B + modo + tabela de resultados.

### Why

Álgebra cross-linguística sobre DuckDB permite joins SQL diretos (inner/left) entre corpora de línguas diferentes usando glosas em português como pivô. O resultado é uma tabela de corpus salvável (F3 futura via `CREATE TABLE AS`). Índice em memória = zero latência de leitura + reconstruível sem estado persistente.
