## YG-71 — Per-universe changelog via git pathspec (jj-compatible, sem submodules)

Adicionado `scripts/universe-changelog.sh`: gera e mantém `CHANGELOG.md` independente
para cada universo filtrado por `git log -- universes/universe-<slug>/`, sem submodules.

### Funcionalidades

- `universe-changelog.sh <slug>` — gera/atualiza seção `[Unreleased]` do CHANGELOG do universo.
- `universe-changelog.sh --all` — processa todos os universos com `status: embedded` e `versions_tracked: true` no `REGISTRY.yaml`.
- `universe-changelog.sh <slug> --bump patch|minor|major` — congela `[Unreleased]` como versão X.Y.Z e bumpa `Cargo.toml`.
- `universe-changelog.sh --check` — retorna exit 1 se algum CHANGELOG está atrás dos commits no path (apto para CI e lefthook).
- jj-compatible: leitura pura do histórico git; se `jj` estiver no PATH, adiciona nota ao header `[Unreleased]`.

### Why

Permite que cada universo tenha histórico rastreável sem submodules. Quando/se um
universo migrar para repo próprio (v2.x), o histórico filtrado vira a base via
`git filter-repo`.

Documentação adicionada em `docs/UNIVERSE-VERSIONING.md`.
