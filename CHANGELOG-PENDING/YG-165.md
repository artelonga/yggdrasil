## YG-165 — Admin de apoios (listar pledges + confirmar pela UI)

Operar a campanha não precisa mais de `curl`: uma tela mostra os apoios que
chegam e confirma o pagamento quando o PIX cai. Fecha a operabilidade do
crowdfunding (YG-161/163/164).

### Added
- **`GET /api/v1/campanha/pledges`** (admin, `YGGDRASIL_ADMIN_TOKEN`) — lista
  **completa** dos apoios (inclui `email`/`user_sub`). É a **única** rota que
  expõe PII, e só atrás do admin token; as públicas (`/creditos`, `/progresso`)
  seguem sem PII. `PledgeDb::list_all()`.
- **Página `/campanha/admin`** (fora da nav pública, `noindex`): pede o admin
  token (guardado só em `sessionStorage`), lista os apoios (tier, valor, nome,
  e-mail, recado, status, data) e **confirma** pendentes por linha → reusa
  `POST /pledges/{id}/confirmar` (credita as sementes do tier).
- Helper `check_admin` compartilhado por confirmar + listar (mesmo gate).

### Tests
- API: `GET /pledges` 401 sem token; 200 com admin (traz e-mail só aqui);
  `/creditos` continua sem e-mail.
- e2e `campanha-admin`: gate 401/200, e-mail só na visão admin; a página lista e
  confirma um apoio (pendente→confirmado, contagem sobe).

### Segurança
PII (e-mail/`user_sub`) só sai por `GET /pledges`, admin-gated. Nenhuma rota
pública mudou.
