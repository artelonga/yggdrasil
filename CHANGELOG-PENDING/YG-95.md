## YG-95 — Notas de universo (Phase 0): conteúdo Markdown ligado por wikilinks

Sistema de **notas** no editor de instâncias: cada nota é um Markdown canônico em
`/data/instances/<id>/notes/<slug>.md`, ligado por `[[wikilinks]]` (semântica idêntica
ao `co`), com backlinks e grafo. Um bloco-nota referencia o arquivo via `props.note_slug`.

- `NoteStore` (`yggdrasil-core/src/instance/note.rs`) — escrita atômica, parser de
  wikilinks, backlinks, grafo de adjacência.
- 4 rotas REST `PUT/GET/DELETE /api/v1/instances/{id}/notes[/{slug}]` + list com
  backlinks/grafo (`yggdrasil-web/src/api/instances.rs`).
- Editor (`static/universos/instance.js`): render Markdown (HTML-escapado), wikilinks
  clicáveis, arestas tracejadas de wikilink no canvas, editor de corpo, sidebar "Notas".
- `SCHEMA_VERSION` 1 → 2 (aditivo; instâncias v1 carregam sem migração).

Shipado em prod (`yggdrasil-artelonga.fly.dev`) em 2026-06-06; este commit traz o código
para o controle de versão. Parte do épico YG-94 (Content + Messaging GA, v2.2.0).
