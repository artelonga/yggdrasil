## YG-156 — Integração MundoView — fundir YG-151 (fullscreen + vault inteiro LAZY) sobre o YG-154 mergeado (drag-drop durável), preservando memory-light

O `mundo/loader.js` e o `mundo/instance-view.js` divergiram em PRs paralelos: o
YG-154 (mergeado) trouxe um loader **eager** (`byId` de TODAS as salas) com
drag-drop durável; o YG-151 (PR #85, supersedido) trouxe um loader **lazy**
(`ids` + `get(id)`) com tela cheia + vault inteiro navegável. Esta tarefa **folda**
o drag-drop durável sobre a base lazy, num único surface coeso — sem merge textual
frágil (que compilaria mas quebraria em runtime, pois o `findNote` do 154 varre um
`byId` que o lazy não tem).

### `mundo/loader.js` — loader lazy COM layout persistido folado
- Mantém `{ rootId, ids, get }` (lazy: cada `Room` só é construída ao entrar, com
  cache; o vault inteiro é navegável via `ids` sem materializar `byId` eager) e
  expõe **`roomOf(slug)`**.
- **Pré-computa overrides** do `.md` numa passada barata (sem layout):
  `layoutOverride[slug] = { room?, x?, y? }` de `n.parent || n.pos.room` + `n.pos.x/y`.
- **Membership efetiva** (reparent): cada nota-folha entra em `notesInRoom[room]`,
  onde `room = override.room` (se válido) ou a sala estrutural (`parentOf || ROOT`).
  Assim `get(id)` inclui as notas reparenteadas PRA `id` e exclui as movidas pra
  FORA — sem construir as outras salas.
- `get(id)` sobrepõe o `x/y` persistido em cada objeto após o auto-layout.

### `mundo/instance-view.js` — API união
- De **YG-151**: `get rooms()` → `rooms.ids`, `get fullscreen()`, `toggleFullscreen`
  (botão da HUD `⛶` + tecla `F`, Fullscreen API no palco), `room(id)` = `loader.get(id)`.
- De **YG-154**: `enter`, `posOf`, `drag`, `reparent`, drag-drop → `coordMap` →
  commit em lote (`POST /layout`) → `.md`/CO.
- **`findNote(slug)`** re-apontado: resolve a sala efetiva via `coordMap` (movimentos
  da sessão) ou `loader.roomOf(slug)` — **sem varrer `byId`** (que não existe no lazy).

### Frontend / e2e
- `instance.html`: botão `#mundo-fs` (tela cheia) + CSS, restaurados do YG-151.
- e2e Playwright (`e2e/tests/mundo.spec.js`): novo teste full-experience cobrindo
  loader lazy (vault ≥3 níveis) + fullscreen (entra/sai) + drag→reload→posição
  mantida + reparent→reload→muda de sala, tudo no `window.MundoView`.

### Why
Token/memory efficiency é prioridade do dono → o loader LAZY (151) é a base e o
layout persistido (154) folda nele, fechando o full-experience do Mundo (vault
inteiro memory-light + drag-drop durável) sem regressão e sem merge frágil.
