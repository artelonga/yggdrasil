## YG-100 — Write-back de contribuições de léxico para git

### Adicionado
- Motor de write-back (`comunicacao/writeback.rs`) que versiona as contribuições
  `_users/` no checkout `comunicacao` via `git add`/commit (push best-effort),
  para que palavras publicadas **persistam** num redeploy/restart e entrem no
  repo de léxico curável.
- Disparo **não-bloqueante** após `publicar` (só quando cria arquivo novo) +
  **rede de segurança periódica** (a cada 5 min) que sincroniza contribuições
  ainda não commitadas.

### Detalhes
- Env-gated por `YGGDRASIL_COMUNICACAO_WRITEBACK` (desligado por padrão = no-op).
  Identidade de commit local via `-c user.name/user.email` (config
  `YGGDRASIL_COMUNICACAO_GIT_NAME`/`_EMAIL`); reusa `COMUNICACAO_DIR` como repo.
- Idempotente (`git diff --cached --quiet` evita commit vazio); faz stage só de
  caminhos sob `_users/`; tolera diretório não-git sem panic.
