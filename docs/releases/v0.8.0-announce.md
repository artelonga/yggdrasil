# Yggdrasil v0.8.0 — Pôquer multiplayer + universos como grafo

> Lançado em 2026-05-13. Tag: `v0.8.0`.
> Demo ao vivo: <https://yggdrasil-artelonga.fly.dev/>

A primeira release de Yggdrasil com gameplay multiplayer real. O universo
Pôquer atinge paridade com Snake / Tetris / Invaders e introduz dois conceitos
arquiteturais que vão reger as próximas versões: **identidade unificada
artelonga** e **universos como grafo recursivo**.

## Para quem vai jogar

- Acesse <https://yggdrasil-artelonga.fly.dev/lobby>.
- Caminhe (WASD ou clique) até um dos 4 portais — 🐍 Snake, 🟦 Tetris, 👾 Invaders, 🃏 Pôquer.
- Pôquer agora exige login. Entre com Google ou com email (código de 6 dígitos enviado pelo CO).
- Para jogar pôquer:
  - Buy-in de **1.000 sementes** por sentar (carteira inicia com 0 — Google login ainda não dá sementes iniciais; será corrigido).
  - 3 mesas disponíveis: Mesa Carvalho (6 seats, cash game), Mesa Olmo (6 seats, cash game), Heads-Up Carvalho (2 seats, duelo).
  - Sentar com 1 humano → bot Carvalho aparece como oponente.
  - 2º humano senta → bot sai automaticamente. Banner "Convide um amigo" mostra a URL da mesa.
  - Cartas: deal → pre-flop → flop → turn → river → showdown. Botões fold/check/call/raise aparecem só na sua vez.

## Para quem programa

### Universos como grafo recursivo

Cada jogo virou um **nó** num grafo navegável via API:

```
GET /api/v1/universes              → todos os 12 nós (4 roots + 8 variantes)
GET /api/v1/universes/tetris       → root tetris com children
GET /api/v1/universes/tetris/sprint-40 → variante com parameters: {lines_to_clear: 40, mode: "sprint"}
GET /api/v1/universes/graph        → {nodes, edges} para visualizadores
```

Variantes não estendem o root — **instanciam** o engine raiz com overrides de
parâmetros. `snake/walls` é Snake + obstáculos internos. `tetris/sprint-40` é
Tetris que termina ao limpar 40 linhas. `poker/heads-up` é Pôquer com mesa de
2 assentos. Composição sobre herança.

Forward-compat com a POC Godot (YG-31..YG-35): o mesmo grafo corresponde a
uma árvore de `.tscn` scenes — root = scene principal, variante = sub-scene
que `.instance()` da root + props alteradas.

Ver `docs/ARQUITETURA-UNIVERSOS.md` para detalhes.

### SSO unificado entre apexes

Yggdrasil não tem mais seu próprio backend de email/password. Login por
**Google** e **email-código** ambos roteiam para CO:

- Google: `Yggdrasil /login` → `CO /api/v1/auth/google/start` → CO callback → CO redirect com `co_token` ES256.
- Email-código: `Yggdrasil /login` → `CO /api/v1/auth/onboard-with-email` (CORS) → CO envia código (SMTP do CO) → cliente faz verify no CO → navega para `CO /auth/co-handover` → bounce de volta com `co_token`.
- Em ambos: `Yggdrasil /auth/co-handover-receive` valida `co_token` via JWKS de CO, mintar JWT HS256 local, armazena em `localStorage.yggdrasil-jwt`.

Mesma identidade entre `co.artelonga.com.br`, `quilomboaraucaria.org`, e
`yggdrasil-artelonga.fly.dev`. Adicionar um quarto apex é só inserir no
safelist de CO.

### Carteira de sementes per-user

`Sementes::saldo/debitar/creditar` agora opera por `user_id` via
`storage.get_wallet_for_user` / `save_wallet_for_user`. Bug pré-existente:
o `WalletManager` do `game-core` ignora `user_id` e usa wallet global —
funcionava em single-player mas teria misturado saldos no multiplayer.

## Mudanças notáveis

### Added

- **Pôquer multiplayer completo** (YG-22..27): lobby seating com regra de bot, gameplay (deal/bet/showdown), bot AI random, buy-in/cash-out em sementes.
- **Login UI** com botão "Continuar com Google" + form de email-código.
- **Lobby `/lobby`** com auth area (login/logout), painel de high scores top 3 por universo, atividade recente, placeholder de reviews.
- **Rotas de universos**: `/universos/snake|tetris|invaders|poker` (renomeadas de `/games/*`, com 301 redirects).
- **Grafo de universos** (YG-36): registry + 3 endpoints públicos.
- **Variantes parametrizam engines** (YG-37): `snake/walls`, `tetris/sprint-40`, `invaders/swarm`, `poker/heads-up`.
- **SMTP mail provider** (YG-24) opcional, e em seguida deprecated pelo roteamento via CO.
- **Deploy Fly.io**: app `yggdrasil-artelonga` em `gru`, volume `yggdrasil_data`, certificado para `yggdrasil.artelonga.com.br` (pendente DNS).

### Changed

- Auth: signup por email agora vai via CO (sem SMTP no Yggdrasil).
- `Sementes` fix: carteiras por usuário (era global).
- BFS pathfinding do lobby: sem limite hardcoded de 200 nós.

### Fixed

- Portal de pôquer retornava 404; rota registrada.
- Spawn position do avatar do lobby (estava em wall).

## O que NÃO está nesta release

- Frontend dos universos não propaga `?variant=` ainda — variantes acessíveis só via URL direta na API. Lobby variant picker UI vem depois.
- Compositions (`tetris/duel`) permanece como metadata.
- Registry de universos é compile-time; user-generated universes (YG-15 plugin loader) ainda não.
- WebSocket para poker (YG-28) e persistência de mesa em SQLite (YG-29) — poker hoje perde estado em deploys.
- Bot AI de pôquer é random; sem consideração de odds.
- Godot POC (YG-31..YG-35) não iniciada.
